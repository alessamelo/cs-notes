Course Overview

Web Applications

  • Web applications can use technologies such as CSS, JavaScript, and TypeScript.
  • Games created in C, Go, or other advanced languages can be compiled or integrated so that they run inside a browser.
  • HTML is the markup language used to structure web pages and is interpreted by the browser.

Object-Relational Mapping

Object-relational mapping (ORM) is used to convert objects in an application into representations that can be stored in a relational database, and vice versa.

APIs, Requests, Responses, and Routes

  • APIs allow different software components to communicate.
  • A request is sent by a client to ask the server for an operation or resource.
  • A response is returned by the server with the result of the request.
  • Routes define how a server handles requests to particular URLs and HTTP methods.
  • Some web communication mechanisms can keep a connection open so that the server can continue communicating with the client.

Backend Tools

  • Backend frameworks and tools support server-side application development.
  • DNS integration connects domain names with network resources.
  • Web applications may involve code written in different languages, depending on the system architecture.

Testing and Deployment

  • Testing is an important part of software and web engineering.
  • Continuous Integration (CI) automates the integration and testing of code changes.
  • Continuous Deployment (CD) automates the delivery or deployment of software.
  • Containers, such as Docker containers, provide an isolated and reproducible environment for applications.
