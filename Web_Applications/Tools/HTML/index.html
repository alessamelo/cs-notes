HTML Study Notes

A cleaned-up, example-driven walkthrough of core HTML — rewritten from raw study notes into a reference you can actually read, with a live "Result" preview next to every code sample.

Use the menu to jump to any chapter. Every tag mentioned has a runnable example beside its code, so you can see exactly what the browser does with it.

01 Getting Started

The document skeleton

Every HTML page shares the same basic skeleton. The <html> element wraps the whole document, and inside it sit exactly two parts: a <head> (information about the page) and a <body> (what actually shows up in the browser window).

<!DOCTYPE html>
<html>
  <head>
    <title>My First Page</title>
  </head>
  <body>
    <p>Hello, world!</p>
  </body>
</html>
Result

Hello, world!

The text inside <title> doesn't appear on the page — it shows in the browser's tab / title bar instead.

Headings

HTML gives you six levels of heading, <h1> through <h6>, ranked from most to least important. Use them to describe the structure of your content, not just to make text bigger — screen readers and search engines both rely on that structure.

<h1>Heading level 1</h1>
<h2>Heading level 2</h2>
<h3>Heading level 3</h3>
<h4>Heading level 4</h4>
<h5>Heading level 5</h5>
<h6>Heading level 6</h6>
Result

Heading level 1

Heading level 2

Heading level 3

Heading level 4

Heading level 5
Heading level 6

Paragraphs and simple text tags

<p> marks a paragraph. Inside a paragraph, <b> makes text bold and <i> makes it italic purely as a visual style, while <sub> and <sup> drop text below or lift it above the baseline (handy for footnotes or chemical formulas like H2O).

<p>This sentence has <b>bold</b>
and <i>italic</i> text.
Water is H<sub>2</sub>O,
and E = mc<sup>2</sup>.</p>
Result

This sentence has bold and italic text. Water is H2O, and E = mc2.

Whitespace collapsing

Browsers collapse extra spaces, tabs, and line breaks in your source code down to a single space. The only way to reliably start a new visual block of text is to start a new element, such as another <p>.

<p>This      text has
    lots of




    extra whitespace in the source.</p>
Result

This text has lots of extra whitespace in the source.

Notice every gap rendered as a single space — the line breaks in the source were ignored.

02 Formatting Text

Line breaks and horizontal rules

<br /> forces a single line break inside a block of text without starting a new paragraph. <hr /> draws a horizontal rule — typically used to mark a thematic break between sections. Both are self-closing; they never wrap content.

<p>123 Example Street<br />
Springfield<br />
Anytown, USA</p>
<hr />
<p>Content after the rule.</p>
Result

123 Example Street
Springfield
Anytown, USA

Content after the rule.

Strong & emphasis vs. bold & italic

<strong> and <em> look the same as <b> and <i> by default, but they carry meaning: <strong> marks content of strong importance, and <em> marks emphasis that actually changes the meaning of a sentence. Screen readers can announce them differently — <b>/<i> are purely stylistic.

<p><strong>Warning:</strong> do not
unplug the device while it is updating.</p>
<p>I <em>did</em> lock the door.</p>
Result

Warning: do not unplug the device while it is updating.

I did lock the door.

Quotations

Use <blockquote> for longer, block-level quotes (a <p> should sit inside it), and the inline <q> element for short quotes within a sentence. Both accept a cite attribute holding the URL the quote came from.

<blockquote cite="https://example.com/source">
  <p>The best way to predict the future
  is to invent it.</p>
</blockquote>

<p>She said the update was
<q cite="https://example.com/notes">ready to ship</q>.</p>
Result

The best way to predict the future is to invent it.

She said the update was ready to ship.

Abbreviations, citations & definitions

<abbr title="..."> expands an abbreviation on hover. <cite> names the title of a creative work. <dfn> marks the defining instance of a term — note that some browsers don't style it noticeably.

<p><abbr title="Hypertext Markup Language">HTML</abbr>
 is described in <cite>HTML & CSS: Design and Build
 Websites</cite>.</p>
<p>A <dfn>browser</dfn> is a program used
to view websites.</p>
Result

HTML is described in HTML & CSS: Design and Build Websites.

A browser is a program used to view websites.

Author details

<address> holds contact details for the author of the page (or article) — not just any postal address.

<address>
  Written by Jane Doe.<br />
  Visit us at: <br />
  123 Example Street, Springfield<br />
  <a href="mailto:jane@example.com">jane@example.com</a>
</address>
Result
Written by Jane Doe.
Visit us at:
123 Example Street, Springfield
jane@example.com

Marking changes to content

<ins> shows text that has been inserted (usually underlined), <del> shows text that has been deleted (usually struck through), and <s> marks text that is simply no longer accurate or relevant — without implying an edit history.

<p>Price: <del>$40</del> <ins>$30</ins></p>
<p><s>Meeting at 3pm</s> — moved to 4pm.</p>
Result

Price: $40 $30

Meeting at 3pm — moved to 4pm.

03 Lists

Every item in any list — ordered or unordered — is wrapped in an <li> (list item) element.

Ordered and unordered lists

<ol>
  <li>Preheat the oven</li>
  <li>Mix the batter</li>
  <li>Bake for 25 minutes</li>
</ol>

<ul>
  <li>Flour</li>
  <li>Sugar</li>
  <li>Eggs</li>
</ul>
Result

<ol> — ordered

  1. Preheat the oven
  2. Mix the batter
  3. Bake for 25 minutes

<ul> — unordered

  • Flour
  • Sugar
  • Eggs

Definition lists

A definition list uses <dl> as the container, <dt> for each term being defined, and <dd> for its definition.

<dl>
  <dt>HTML</dt>
  <dd>The markup language used to
  structure web pages.</dd>
  <dt>CSS</dt>
  <dd>The language used to style
  those pages.</dd>
</dl>
Result
HTML
The markup language used to structure web pages.
CSS
The language used to style those pages.

Nested lists

A list can be placed inside a list item to build a sub-list.

<ul>
  <li>Fruit
    <ul>
      <li>Apple</li>
      <li>Banana</li>
    </ul>
  </li>
  <li>Vegetables</li>
</ul>
Result
  • Fruit
    • Apple
    • Banana
  • Vegetables

04 Links

Links are what turn a pile of documents into the web. Every link is an anchor element: <a href="...">text the user clicks</a>.

<a href="https://developer.mozilla.org">
  Visit MDN Web Docs
</a>
Result

Visit MDN Web Docs

Absolute vs. relative URLs

TypeExampleWhen to use it
Absolute URLhttps://example.com/about.htmlLinking to a different website
Relative URLabout.html or ../index.htmlLinking between pages of your own site (they must live under the same site structure)

A typical site directory structure

A common pattern: the root folder holds the homepage as index.html, and every sub-folder also has its own index.html as that section's landing page.

site/
├── index.html          <- homepage
├── about/
│   └── index.html
└── products/
    ├── index.html
    ├── widget.html
    └── images/
        └── widget.jpg

From products/widget.html, a link back up to the homepage is a parent reference (../index.html), and one further up would be a grandparent reference (../../index.html).

Email links

<a href="mailto:hello@example.com">
  Email us
</a>
Result

Email us

Opening links in a new tab

The target attribute controls where the link opens. target="_blank" opens it in a new tab or window instead of replacing the current page.

<a href="https://example.com" target="_blank">
  Opens in a new tab
</a>
Result

Opens in a new tab

Linking to a specific part of a page

Give any element an id, then point an <a> at #that-id. On the same page, just use the #id. On a different page, use the full (absolute or relative) URL followed by #id.

<!-- same page -->
<a href="#jump-target">Jump within this page</a>

<!-- a specific section of another page -->
<a href="/notes/chapter4.html#jump-target">
  Jump to a section of another page
</a>

05 Images

The <img> element embeds a picture. It never has a closing tag. src points to the file, alt is descriptive text read aloud by screen readers (and shown if the image fails to load), and title shows a tooltip on hover.

<img src="images/mountain.png"
     alt="Illustration used as a placeholder photo"
     title="A placeholder image" />
Result

The old align attribute (values like left, right, top, middle, bottom) is not part of HTML5 — positioning and alignment belong in CSS now (e.g. float or object-position).

Image formats & resolution

PNG, JPEG and GIF are all bitmap formats made of a grid of pixels. Web images are conventionally exported at 72 ppi, because that's the resolution most browsers actually render at — shipping a higher-resolution file doesn't make it look sharper, it just makes it slower to download. SVG vector images scale to any size without quality loss, though (per the original notes) their browser support was historically inconsistent; today they're widely supported and great for icons and logos.

Animated GIFs

An animated GIF stores several frames in one file to create a simple, looping animation. Because every frame adds to the file size, it's worth keeping frame count and dimensions modest so the page doesn't take too long to load.

Figures & captions

<figure> groups an image with its caption, and <figcaption> holds that caption text.

<figure>
  <img src="images/icon-figure.png"
       alt="Abstract purple placeholder graphic" />
  <figcaption>
    Fig. 1 — a placeholder graphic used
    to demonstrate the figure element.
  </figcaption>
</figure>
Result

06 Tables

A table is a <table> made of rows (<tr>), and each row holds data cells (<td>) or header cells (<th>). The scope attribute on a <th> (values col or row) tells assistive technology whether that header describes a column or a row.

<table>
  <thead>
    <tr>
      <th scope="col">Course</th>
      <th scope="col">Mon</th>
      <th scope="col">Tue</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">HTML</th>
      <td colspan="2">All day workshop</td>
    </tr>
    <tr>
      <th scope="row">CSS</th>
      <td rowspan="2">9am</td>
      <td>2pm</td>
    </tr>
    <tr>
      <th scope="row">JavaScript</th>
      <td>3pm</td>
    </tr>
  </tbody>
  <tfoot>
    <tr><td colspan="3">Room 204 for all sessions</td></tr>
  </tfoot>
</table>
Result
CourseMonTue
HTMLAll day workshop
CSS9am2pm
JavaScript3pm
Room 204 for all sessions

colspan="2" makes a cell span two columns; rowspan="2" makes a cell span two rows. <thead>, <tbody> and <tfoot> group rows for styling and let long tables repeat their header when printed.

Presentational attributes like border, bgcolor, cellpadding, cellspacing and width belonged to old HTML. In HTML5, all of that visual styling is done with CSS instead.

07 Forms

Everything a user fills in lives inside a <form>. Two key attributes: action is the URL of the server-side script that will receive the data, and method is the HTTP method used to send it — commonly GET (for searches / retrieving data, appends data to the URL) or POST (for submitting data, sends it in the request body).

Labelling controls

A <label> ties descriptive text to a form control — clicking the label focuses (or toggles) the control, which matters a lot for accessibility. There are two ways to make that connection:

<!-- Method 1: wrap the input in the label -->
<label>
  Remember me
  <input type="checkbox" name="remember" />
</label>

<!-- Method 2: keep them separate, linked by "for" / "id" -->
<label for="newsletter">Subscribe to newsletter</label>
<input type="checkbox" id="newsletter" name="newsletter" />
Result

Grouping fields & validation

<fieldset> visually and semantically groups related controls, and <legend> gives that group a title (see the "Account details" and "Preferences" groups in the demo form above). Adding required to an input — as done on the email field above — tells the browser to block submission until it's filled in, catching simple mistakes before they ever reach the server. JavaScript is still the right tool for more complex validation rules.

id vs. class

An id must be unique on the page and is typically used as a hook for a single, specific element (a link target, a JavaScript reference). A class can be reused across as many elements as you like, and is the normal way to apply a shared style with CSS.

<p id="intro">Only one element may have id="intro".</p>
<p class="highlight">Many elements can share</p>
<p class="highlight">the same class name.</p>
Result

Only one element may have id="intro".

Many elements can share

the same class name.

Block vs. inline elements

Block-level elements (like <h1>, <p>, <ul>, <li>) start on a new line and take up the full width available. Inline elements (like <em>, <a>, <img>, <b>) flow within a line of text without forcing a break.

Grouping with <div> and <span>

<div> groups a block of related elements together (and starts on its own new line). <span> does the same job inline — either to wrap a run of text that has no more suitable element, or to wrap a handful of inline elements — so you can target that group with CSS or JavaScript.

<div class="card">
  <p>This whole block is one <code>div</code>.</p>
</div>
<p>Some text with a <span class="tag">highlighted
word</span> in the middle.</p>
Result

This whole block is one div.

Some text with a highlighted word in the middle.

Embedding another page with <iframe>

<iframe> displays another HTML document inside a window on your page. Key attributes: src (the page to embed), width / height (its dimensions), scrolling and frameborder (both dropped in HTML5 — use CSS instead), and seamless (an HTML5 attribute for blending the frame into the page).

<iframe src="page-to-embed.html"
        width="400" height="150"
        title="Embedded page">
</iframe>
Result

Information about the page: <meta>

<meta> tags live inside <head> and never have a closing tag. They usually pair a name with content.

<head>
  <title>Information About Your Page</title>
  <meta name="description"
        content="A short summary shown in search results (aim for under 155 characters)." />
  <meta name="keywords"
        content="html, notes, learning" />
  <meta name="robots" content="index, follow" />
  <meta name="author" content="Jon Duckett" />
  <meta http-equiv="cache-control" content="no-cache" />
</head>
NamePurpose
descriptionShort summary shown by search engines — keep it under ~155 characters.
keywordsComma-separated words describing the page's content.
robotsTells search engines whether to index the page and follow its links.
authorNames the page's author.
cache-control / expiresControls whether & how long a browser caches the page.

09 Video & Audio

A bit of history: Flash

Flash was once the standard way to add animation, video and audio to a page — embedded with <object> / <embed> and requiring visitors to install the Flash Player plugin. It was retired years ago and modern browsers no longer support it at all; it's included here only for historical context. Everything below, <video> and <audio>, is the native HTML5 replacement introduced to remove that plugin dependency.

The <video> element

Attributes you'll use most: src (path to the file), poster (an image shown before playback starts), width/height, and four boolean attributes — controls, autoplay, loop, preload — that are simple on/off switches: present means on, omitted means off. preload can also take a value: none, auto, or metadata.

<video src="video/sample.mp4"
       poster="images/poster.png"
       width="320" height="180"
       controls
       preload="metadata">
  <p>Your browser doesn't support HTML5 video.</p>
</video>
Result — a real, playable (silent) sample clip

Multiple sources with <source>

Not every browser supports every video format (H.264/MP4 vs. WebM being the classic split), so list several <source> elements — the browser plays the first one it understands.

<video controls width="320" height="180" poster="images/poster.png">
  <source src="video/sample.webm" type="video/webm" />
  <source src="video/sample.mp4" type="video/mp4" />
  <p>Your browser doesn't support HTML5 video.</p>
</video>
Result

The <audio> element

<audio> shares the same attribute set as <video> (minus the visual ones like poster/width/height), and also supports multiple <source> children for format fallback.

<audio controls>
  <source src="audio/sample.ogg" type="audio/ogg" />
  <source src="audio/sample.mp3" type="audio/mpeg" />
  <p>Your browser doesn't support HTML5 audio.</p>
</audio>
Result — a real, playable tone

Browsers that support <video>/<audio> don't all support the same file formats, which is exactly why shipping more than one <source> format matters.
