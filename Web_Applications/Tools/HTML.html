Chapter 1 — Introduction to HTML

Initialize

<html>
</html>

Parts of a Document

<head>
    <title>Here goes the title displayed in the browser tab</title>
</head>

<body>

</body>

Headers

HTML provides six levels of headings:

<h1>
<h2>
<h3>
<h4>
<h5>
<h6>

Paragraphs and Text Formatting

<p>
<b>Bold</b>
<i>Italic</i>
<sub>Subscript</sub>
<sup>Superscript</sup>

HTML collapses consecutive whitespace characters into a single space. To create a separate paragraph, use another <p> element.

Chapter 2 — Text Formatting and Semantic Elements

Line Breaks

<br>

Creates a line break.

<hr>

Creates a thematic horizontal rule.

Strong and Emphasis

<strong>Strong importance</strong>
<em>Emphasized text</em>
  • <strong> indicates that the content has strong importance.
  • <em> indicates emphasis that can change the meaning or interpretation of a sentence.

Quotations

<blockquote>
    <p>A longer quotation.</p>
</blockquote>

<q>A short quotation.</q>
  • <blockquote> is used for longer quotations.
  • <q> is used for short inline quotations.

The cite attribute can be used to indicate the URL of the source of a quotation. 

<blockquote cite="https://example.com">
    <p>Quotation text.</p>
</blockquote>

Abbreviations

<abbr title="HyperText Markup Language">HTML</abbr>

The title attribute provides the expanded meaning of an abbreviation.

Citations and Definitions

<cite>Title of a work</cite>

<dfn>Term being defined</dfn>
  • <cite> identifies the title of a cited creative work or source.
  • <dfn> identifies a term being defined.

Author Details

<address>
    Author contact information
</address>

The <address> element contains contact information for the author or owner of a page or article.

Changes to Content

<ins>Inserted content</ins>

<del>Deleted content</del>

<s>Content that is no longer accurate</s>
  • <ins> represents content that has been inserted.
  • <del> represents content that has been deleted.
  • <s> represents content that is no longer accurate or relevant.

Chapter 3 — Lists

List Items

Individual terms or items inside ordered and unordered lists are written using the <li> element.

Ordered Lists

<ol>
    <li>First item</li>
    <li>Second item</li>
</ol>

An ordered list displays its items in a particular sequence, usually using numbers.

Unordered Lists

<ul>
    <li>Item one</li>
    <li>Item two</li>
</ul>

An unordered list displays its items without a specific numerical order.

Definition Lists

<dl>
    <dt>HTML</dt>
    <dd>HyperText Markup Language</dd>
</dl>
  • <dl> creates the definition list.
  • <dt> defines the term or title.
  • <dd> contains the description or definition.

Nested Lists

A list can contain another list inside one of its <li> elements. This is called a nested list.

Chapter 4 — Links

Links allow users to navigate between webpages, websites, files, or different parts of the same page.

Creating Links

<a href="URL">Text the user clicks</a>

Absolute and Relative URLs

An absolute URL contains the complete address of a resource. 

https://example.com/about.html

A relative URL specifies the location of a resource relative to the current page. 

about.html
pages/about.html
../about.html

Relative URLs are commonly used when linking between pages within the same website. The pages do not necessarily have to be in the same folder.

Directory Structure

A website commonly has an index.html file as its main or home page. Folders can contain their own pages and resources. 

website/
│
├── index.html
│
├── about/
│   └── index.html
│
├── projects/
│   ├── index.html
│   └── project1.html
│
└── images/

Parent and Grandparent Folders

../

Moves to the parent directory.

../../

Moves to the grandparent directory.

Email Links

<a href="mailto:example@email.com">
    Send me an email
</a>

The mailto: scheme can be used to create a link that opens the user's default email application.

Target Attribute

<a href="https://example.com" target="_blank">
    Open website
</a>

The target attribute determines where the linked resource opens. _blank commonly opens it in a new browsing context.

Links to Specific Parts of a Page

An element can have an id that can be used as a destination for a link. 

<h2 id="projects">Projects</h2>

<a href="#projects">Go to Projects</a>

Links to a Specific Part of Another Page

The same technique can be used with another page by adding the fragment identifier after the URL. 

<a href="about.html#projects">
    Go to Projects
</a>

Chapter 5 — Images

Adding Images

<img src="image.jpg" alt="Description of the image" title="Image title">
  • src specifies the path or URL of the image.
  • alt provides alternative text describing the image.
  • title can provide additional information about the image.

The <img> element is a void element, so it does not require a closing tag.

Image Alignment

Older HTML versions allowed attributes such as align to control image positioning. This is obsolete in modern HTML. CSS should be used for image positioning and layout.

Image Formats

  • JPEG/JPG: commonly used for photographs.
  • PNG: supports transparency and lossless compression.
  • GIF: supports simple animations and a limited color palette.
  • SVG: a vector format commonly used for logos, icons, and illustrations.

For web images, the important factors are pixel dimensions, file size, compression, and the appropriate image format. A specific PPI value such as 72 PPI is not required for web images.

Vector Images

Vector images can be represented using formats such as SVG. Unlike bitmap images, vector graphics can scale to different sizes without losing their mathematical definition.

Animated GIFs

Animated GIFs contain multiple frames that are displayed sequentially to create simple animations. File size should be considered because large GIFs can increase page loading time.

Figures and Captions

<figure>
    <img src="image.jpg" alt="Description">
    <figcaption>Caption for the image</figcaption>
</figure>

The <figure> element groups self-contained content such as images, diagrams, or illustrations. <figcaption> provides a caption for that content.

Chapter 6 — Tables

Basic Table Structure

<table>
    <tr>
        <td>Data</td>
        <td>Data</td>
    </tr>
</table>
  • <table> creates the table.
  • <tr> creates a table row.
  • <td> creates a data cell.
  • <th> creates a header cell.

Table Headers and Scope

<th scope="col">Name</th>
<th scope="row">Student 1</th>

The scope attribute helps identify whether a header applies to a column or a row and improves the semantic structure and accessibility of tables.

Spanning Columns and Rows

<td colspan="2">
    Cell spanning two columns
</td>

The colspan attribute specifies how many columns a cell should span. 

<td rowspan="2">
    Cell spanning two rows
</td>

The rowspan attribute specifies how many rows a cell should span.

Organizing Long Tables

<table>

    <thead>
        ...
    </thead>

    <tbody>
        ...
    </tbody>

    <tfoot>
        ...
    </tfoot>

</table>
  • <thead> contains the header rows.
  • <tbody> contains the main table data.
  • <tfoot> contains footer or summary rows.

Older HTML versions included presentation-related table attributes such as border, bgcolor, cellpadding, cellspacing, and width. In modern HTML, CSS should be used for presentation and layout.

Chapter 7 — Forms

Form Element

<form action="URL" method="post">

    ...

</form>

The <form> element contains form controls and defines how their data is submitted.

Form Attributes

  • action: specifies the URL where the form data should be submitted.
  • method: specifies how the form data is submitted. The standard HTML form methods are GET and POST.
  • id: uniquely identifies the form and can be referenced by other elements or scripts.

Input Element

<input type="text" name="username">

The <input> element creates different types of form controls depending on its type attribute.

Important Input Attributes

  • type: determines the type of form control.
  • name: identifies the form field when its data is submitted.
  • id: uniquely identifies the individual control.
  • maxlength: specifies the maximum number of characters allowed in text input.
  • value: specifies the value associated with the control.
  • placeholder: displays temporary guidance inside certain form controls.
  • required: indicates that the user must provide a value before submitting the form.

Input Types

Text

<input type="text" name="name">

Creates a single-line text input.

Password

<input type="password" name="password">

Displays entered characters in a masked form. This does not by itself make the data secure. Secure transmission requires appropriate server and transport security, such as HTTPS.

Radio

<input type="radio" name="gender" value="female">
<input type="radio" name="gender" value="male">

Radio buttons are used when the user should select one option from a group. Radio buttons that belong to the same group normally share the same name. 

<input type="radio" name="gender" value="female" checked>

The checked attribute specifies that a checkbox or radio button is selected by default.

Checkbox

<input type="checkbox" name="interest" value="programming">

Checkboxes allow the user to independently select or deselect options. Multiple checkboxes can be selected.

File

<input type="file" name="document">

Creates a control that allows the user to select a file from their device.

Submit

<input type="submit" value="Submit">

Creates a button that submits the form.

Image

<input type="image" src="submit.png" alt="Submit">

Creates a graphical submit control using an image.

Hidden

<input type="hidden" name="userID" value="123">

Creates a form control that is not displayed to the user but can still be included when the form is submitted. Hidden inputs are not secure or secret; their values can be inspected and modified by the user.

Date

<input type="date" name="birthdate">

Provides a control for selecting a date.

Email

<input type="email" name="email">

Allows the user to enter an email address and provides built-in browser validation when appropriate.

URL

<input type="url" name="website">

Allows the user to enter a URL and provides built-in browser validation when appropriate.

Search

<input type="search" name="query" placeholder="Search...">

Creates a single-line search field. The placeholder attribute can display temporary instructional text inside the control.

Textarea

<textarea name="message"></textarea>

The <textarea> element creates a multiline text input. Its visual dimensions can be controlled using HTML attributes or CSS. Form data should always be validated on the server, regardless of any client-side validation.

Select and Option

<select name="country">
    <option value="ec">Ecuador</option>
    <option value="us">United States</option>
    <option value="ca">Canada</option>
</select>
  • <select> creates a dropdown or selection control.
  • <option> defines an available option.
  • value defines the value submitted for the selected option.

Selected Option

<option value="ec" selected>Ecuador</option>

The selected attribute makes an option selected by default. It does not by itself prevent an empty value from being submitted.

Multiple Selection

<select name="interests" multiple>
    <option value="programming">Programming</option>
    <option value="research">Research</option>
    <option value="painting">Digital Painting</option>
</select>

The multiple attribute allows the user to select more than one option. The size attribute can control how many options are visible at once.

Button

<button type="submit">Submit</button>

The <button> element creates a button and provides more flexibility than <input type="submit"> because content such as text and other HTML can be placed inside it.

Labels

<label>
    Age:
    <input type="text" name="age">
</label>

The <label> element indicates that text describes a specific form control. Labels improve accessibility and make forms easier to use.

Two Ways to Associate a Label with a Control

Method 1 — Put the Input Inside the Label
<label>
    Age:
    <input type="text" name="age">
</label>

The relationship is automatic because the form control is contained inside the <label>.

Method 2 — Use the for Attribute
<label for="age">Age:</label>
<input type="text" id="age" name="age">

The for attribute connects the label to the form control whose id has the same value. 

for="age"
    ↓
id="age"

This allows users to click the label to activate or focus the associated form control.

Grouping Form Elements

<fieldset>

    <legend>Personal Information</legend>

    <label for="name">Name:</label>
    <input type="text" id="name" name="name">

</fieldset>
  • <fieldset> groups related form controls together.
  • <legend> provides a caption or title for the fieldset.

Form Validation

HTML5 provides several built-in validation mechanisms, so basic validation does not always require JavaScript. 

<input type="email" required>

The required attribute indicates that the user must provide a value before submitting the form.

Other HTML validation attributes include:

  • required — value must be provided.
  • minlength — minimum number of characters.
  • maxlength — maximum number of characters.
  • min — minimum numerical or date value.
  • max — maximum numerical or date value.
  • pattern — value must match a specified pattern.
  • type="email" — provides email-oriented validation.
  • type="url" — provides URL-oriented validation.

Client-side HTML validation improves the user experience, but it should not replace server-side validation. Data received by a server should always be validated on the server because client-side controls can be bypassed.
