Bootstrap

What is Bootstrap?

Bootstrap is a front-end framework that makes web development faster and easier. It provides pre-designed HTML and CSS components for typography, forms, buttons, navigation, tables, and many other interface elements.

Bootstrap can also be complemented with JavaScript plugins that provide interactive functionality such as dropdowns, alerts, modals, spinners, and other dynamic components.

Bootstrap also helps developers create responsive websites.

What is Responsive Design?

Responsive web design is the process of creating a website that automatically adjusts its layout and content to different screen sizes, from small mobile phones to large desktop screens.

  • Easy to use.
  • Responsive features.
  • Mobile-first approach.
  • Browser compatibility.

How to Use Bootstrap

Bootstrap can be used in two main ways:

  1. Include Bootstrap using a CDN.
  2. Download Bootstrap and host the files on your own server.

What does .min mean?

Files ending in .min.css or .min.js are minified. Minification removes unnecessary spaces, line breaks, and other characters to reduce the file size and improve loading speed.

Downloading Bootstrap Instead of Using a CDN

Bootstrap files can be downloaded and hosted directly on the application's server.

Some advantages include:

  • Reduced dependency on external services.
  • The application can still access Bootstrap if the external CDN is unavailable.
  • More control over the files and versions used by the application.
  • Useful in environments with limited or restricted internet access.

However, a CDN can often provide faster loading because its servers may be geographically closer to users and optimized for delivering static files.

Bootstrap Containers

.container

The .container class provides a responsive, fixed-width container.

It leaves space on the left and right sides of the content. The container width adapts at different Bootstrap breakpoints.

Bootstrap Typography

Bootstrap uses a default font size of 1rem, which is usually equal to 16px. Its default line height is approximately 1.5.

Paragraph elements have a default top margin of 0 and a bottom margin of approximately 1rem.

Bootstrap Tables

Bootstrap provides classes to improve the appearance of tables.

HTML tables can include sections such as:

  • <thead>: Table header.
  • <tbody>: Table body.
  • <tfoot>: Table footer.

In a dynamic table, the body may initially be empty and rows can be generated when data is retrieved from a database.

Pagination can also be used with tables to display a limited number of records per page, reducing the amount of data requested and displayed at once.

Advanced features such as exporting tables to Excel, searching, sorting, and hiding columns can be implemented using libraries such as DataTables.

What is the integrity Attribute?

The integrity attribute, often containing a value such as sha384-..., is used for Subresource Integrity (SRI).

It allows the browser to verify that a file loaded from a CDN has not been modified unexpectedly. The browser compares the downloaded file against the cryptographic hash provided in the integrity attribute.
