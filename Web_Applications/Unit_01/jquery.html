1. What is jQuery?

jQuery is a JavaScript library whose objective is to simplify JavaScript programming, especially when working with web pages and the DOM.

Main idea:

"Write less, do more."

jQuery provides a simpler syntax for common tasks such as:

  • Selecting HTML elements.
  • Modifying HTML content.
  • Changing attributes.
  • Changing CSS.
  • Adding and removing classes.
  • Handling events.
  • Creating animations and effects.
  • Manipulating the DOM.

Instead of writing verbose DOM manipulation code using document.querySelector(), addEventListener(), and other browser APIs, jQuery provides shorter abstractions for many common operations.

2. jQuery Version

The version used in these notes is:

jQuery 4.0.0

jQuery 4.0.0 was released in January 2026.

jQuery 4 is a modern major release that removes some legacy behavior and makes several changes compared with previous versions.

3. How to Use jQuery

There are two common approaches to include jQuery in an HTML document:

Option 1 — Download the Library

We can download the jQuery file and store it inside our project. 

<head>

    <script src="js/jquery-4.0.0.min.js"></script>

</head>

The exact path depends on where the file is located in the project.

Option 2 — Use a CDN

Instead of downloading jQuery, we can load it from a Content Delivery Network (CDN). 

<head>

    <script src="https://code.jquery.com/jquery-4.0.0.min.js"></script>

</head>
The URL must point to an actual jQuery distribution file. A generic URL such as https://code.js is not a valid jQuery CDN reference.

4. Adding Our Own JavaScript

After loading jQuery, we can load our own JavaScript file. 

<head>

    <script src="https://code.jquery.com/jquery-4.0.0.min.js"></script>

    <script src="js/script.js"></script>

</head>

Our script can then use the jQuery API because the jQuery library has already been loaded.

5. Basic jQuery Syntax

Basic syntax: 
$(selector).action();

The $ symbol is the conventional shorthand used by jQuery to access the jQuery function.

The selector identifies one or more elements in the document.

The action specifies what we want to do with the selected elements.

Example

$("#title").text("Hello");

This selects the element with the ID title and changes its text.

6. Document Ready

jQuery provides a way to execute code when the DOM has finished loading. 

$(document).ready(function() {

    // jQuery code here

});

A shorter equivalent syntax is: 

$(function() {

    // jQuery code here

});
The callback runs when the DOM is ready to be manipulated. It does not necessarily wait for every external resource, such as every image, to finish loading.

7. jQuery Selectors

jQuery selectors are based largely on CSS selector syntax. They allow us to select one or multiple elements.

Select All Elements

$("*")

Selects all elements in the document.

Select by ID

$("#myId")

Selects the element whose ID is myId.

Select by Element

$("p")

Selects all paragraph elements.

Select by Class

$(".intro")

Selects all elements with the class intro.

Select a Specific Combination

$("p.intro")

Selects paragraph elements that have the class intro.

First Element

$("p:first")

Selects the first paragraph element.

First Child

$("ul li:first-child")

Selects every li that is the first child of its parent.

Attribute Selector

$("[href]")

Selects elements that have an href attribute.

Attribute Value

$("a[target='_blank']")

Selects links whose target attribute is _blank.

this

$(this)

$(this) wraps the current DOM element in a jQuery object, commonly inside an event handler.

8. text()

The text() method gets or changes the text content of an element.

Get Text

let content = $("#title").text();

Set Text

$("#title").text("New title");
text() treats the supplied value as text. HTML markup is not interpreted as HTML.

9. val()

The val() method is used to get or set the value of form elements.

Get a Value

let username = $("#username").val();

Set a Value

$("#username").val("Alice");

It is commonly used with elements such as:

  • <input>
  • <textarea>
  • <select>
Remember:

text() → text content of an element
val() → value of a form control

10. html()

The html() method gets or changes the HTML content inside an element.

Get HTML

let content = $("#container").html();

Set HTML

$("#container").html("<strong>Hello</strong>");

Unlike text(), HTML markup supplied to html() can be interpreted as HTML.

Be careful when inserting external or untrusted content with html(), because inserting unsafe HTML can create security vulnerabilities such as XSS.

11. attr()

The attr() method is used to get or set HTML attributes.

Get an Attribute

let link = $("a").attr("href");

Set an Attribute

$("#image").attr("src", "image.jpg");

It can be used with attributes such as:

  • src
  • href
  • alt
  • title
  • id

12. append() and prepend()

These methods insert content inside a selected element.

append()

$("#list").append("<li>New item</li>");

append() adds content at the end of the selected element.

prepend()

$("#list").prepend("<li>First item</li>");

prepend() adds content at the beginning of the selected element.

Inside an element:

prepend → content → existing content → append

13. before() and after()

Unlike append() and prepend(), before() and after() insert content outside the selected element.

before()

$("#image").before("<p>Before the image</p>");

Inserts content immediately before the selected element.

after()

$("#image").after("<p>After the image</p>");

Inserts content immediately after the selected element.

Difference:

append() → inside, at the end
prepend() → inside, at the beginning
before() → outside, before the element
after() → outside, after the element

14. addClass(), removeClass(), toggleClass()

addClass()

$("#box").addClass("active");

Adds a CSS class to the selected element.

removeClass()

$("#box").removeClass("active");

Removes a CSS class.

toggleClass()

$("#box").toggleClass("active");

Adds the class if it is absent and removes it if it is present.

toggleClass() is useful when an interaction should switch an element between two visual states.

Example

$("#menuButton").click(function() {
    $("#menu").toggleClass("open");
});

15. css()

The css() method gets or sets CSS properties.

Get a CSS Property

let color = $("#title").css("color");

Set a CSS Property

$("#title").css("color", "red");

Set Multiple Properties

$("#box").css({
    "width": "200px",
    "height": "100px",
    "font-size": "20px"
});

However, for reusable visual states, using addClass(), removeClass(), and toggleClass() is often cleaner than directly modifying many CSS properties with JavaScript.

16. Events

jQuery provides methods for responding to browser events.

click()

$("#button").click(function() {

    $("#message").text("Button clicked");

});

The function executes when the selected element is clicked.

Other Common Events

$("#input").focus(function() {
    // Executes when the input receives focus
});

$("#input").blur(function() {
    // Executes when the input loses focus
});

$("#form").submit(function(event) {
    // Executes when the form is submitted
});

17. Complete Example

HTML

<button id="button">Change Text</button>

<p id="message">Original text</p>

<input id="username" type="text" value="Alice">

<div id="box">Box</div>

jQuery

$(document).ready(function() {

    $("#button").click(function() {

        $("#message").text("The text has changed");

        $("#box").toggleClass("active");

    });

});

In this example:

  1. jQuery waits until the DOM is ready.
  2. The button is selected using its ID.
  3. A click event is registered.
  4. The paragraph's text is changed using text().
  5. A CSS class is toggled using toggleClass().

18. Important jQuery Methods

Method Purpose Example

19. Selector Summary

Selector Meaning
$("*") All elements.
$("#myId") Element with the specified ID.
$(".intro") Elements with the specified class.
$("p") All paragraph elements.
$("p.intro") Paragraphs with class intro.
$("ul li") All li elements inside ul.
$("ul li:first") First matched li.
$("ul li:first-child") li elements that are first children.
$("[href]") Elements containing an href attribute.
$("a[target='_blank']") Links whose target is _blank.
$(this) The current element inside a callback/event handler.

20. Key Points to Remember

  • jQuery is a JavaScript library.
  • Its purpose is to simplify common JavaScript operations, particularly DOM manipulation and event handling.
  • The $ symbol is commonly used to access jQuery.
  • The basic pattern is $(selector).action().
  • jQuery selectors are largely based on CSS selector syntax.
  • $(document).ready() runs code when the DOM is ready.
  • text() manipulates text content.
  • val() manipulates form values.
  • html() manipulates HTML content.
  • attr() manipulates HTML attributes.
  • append() and prepend() insert content inside an element.
  • before() and after() insert content outside an element.
  • addClass(), removeClass(), and toggleClass() manipulate CSS classes.
  • css() manipulates CSS properties.

21. Final Summary

jQuery = JavaScript library for simplifying browser programming. 
$(selector).action();

The general workflow is: 

Select
   ↓
Manipulate
   ↓
Respond to events
   ↓
Modify the DOM / CSS

For example: 

$("#button").click(function() {

    $("#message").text("Hello");

});

This selects an element, listens for an event, and modifies another element when the event occurs.
