Web Applications: JavaScript

Date: September 1, 2026

1. Introduction

  • JavaScript (JS) was created to add dynamic behavior and activity to web pages.
  • It is a lightweight programming language.
  • JavaScript is commonly executed by the browser through its JavaScript engine.
  • JavaScript code is usually embedded directly into an HTML document or loaded from an external .js file.
  • JavaScript was originally created for use with HTML and browsers.
  • It is freely usable.
  • JavaScript is mainly used to dynamically manipulate web pages.

Web development roles

Technology Main role
HTML Structure / content
CSS Presentation / appearance
JavaScript Behavior / interactivity

JavaScript can make a website richer when dynamic behavior is needed, but it is not mandatory for every website.

2. Java vs. JavaScript

Java and JavaScript are not the same language.

They are different in their concepts, design, and typical uses.

Java

  • Object-oriented programming language.
  • Developed by Sun Microsystems.
  • Designed as a more complex general-purpose programming language.
  • Was designed with goals including portability and performance.
  • It was developed partly in the context of competing with languages such as C and C++.

JavaScript

  • Designed originally for web browsers and HTML.
  • The name JavaScript was influenced by the popularity of Java, but the languages are fundamentally different.
  • JavaScript is generally more flexible and dynamically typed.

3. Interpreted and Compiled Languages

In the course, Python was described as an interpreted language.

For JavaScript:

The program that interprets/executes JavaScript in a normal web page is the browser's JavaScript engine.

The browser reads the HTML document and executes the JavaScript associated with it.

Modern JavaScript engines internally perform compilation and optimization, so the simple distinction "JavaScript = interpreted" is an oversimplification. For these notes, however, the important point is that the browser provides the environment that executes JavaScript.

4. Advantages of JavaScript

Usability

JavaScript can modify a web page without requiring a request to the server for every interaction.

For example:

  • Validating user input.
  • Changing elements on the page.
  • Responding to button clicks.
  • Updating the user interface.

This can make the UI feel faster and more interactive.

Efficiency

JavaScript allows some operations to happen directly in the browser instead of constantly communicating with the server.

5. Including JavaScript in HTML

JavaScript can be placed directly inside an HTML document using <script>: 

<script>
    alert("Using JavaScript");
</script>

It can also be placed in an external JavaScript file, similar to how CSS can be placed in an external stylesheet.

6. Example: JavaScript Event

<html>
<body style="background: gray; border: groove;">

<h1 style="background: blue;"
    onclick="alert('Using JavaScript')">
    Hello World!
</h1>

</body>
</html>

When the user clicks the <h1>, JavaScript executes: 

alert("Using JavaScript");

and displays an alert.

7. JavaScript Syntax

A statement is an instruction executed by the program.

In Python, a new line generally indicates the end of a statement.

In JavaScript, semicolons ; are commonly used, but they are often optional because JavaScript has Automatic Semicolon Insertion (ASI).

Example

var value1 = 10;
var value2 = 10;
var result = value1 + value2;

9. Whitespace and Newlines

Spaces, tabs, and newlines are generally ignored when they do not affect the syntax.

They can therefore be used to make code easier to read. 

var value1 = 10;
var value2 = 20;
var result = value1 + value2;

Formatting improves readability but normally does not change the meaning of the code.

This differs from Python, where indentation is syntactically significant.

13. Increment Operators

Pre-increment

var value1 = 10;
var value2 = 10;

var result = ++value1 + value2;

alert(result);

The result is:

21

++value1 is pre-increment:

  1. Increase value1 from 10 to 11.
  2. Use 11 in the expression.
  3. Calculate 11 + 10 = 21.

Post-increment

var value1 = 10;
var value2 = 10;

var result = value1++ + value2;

alert(result);

The result is:

20

Because value1++ is post-increment:

  1. Use the current value 10.
  2. Calculate 10 + 10 = 20.
  3. Afterwards, increase value1 to 11.
Expression Value used Value afterwards
++value1 11 11
value1++ 10 11

14. The + Operator

The + operator can perform different operations depending on the data types.

Numbers

10 + 20

Produces:

30

Strings

With strings, + can concatenate: 

var value1 = "hello";
var value2 = "world";

var result = value1 + value2;

Result:

helloworld

This is sometimes described as operator overloading because the same operator can perform different operations depending on the operands.

value1++value2 is not valid syntax for string concatenation. Use value1 + value2.

15. Strings

Strings can be enclosed using either single or double quotation marks: 

"Hello"

or:

'Hello'

You can use the other type of quotation mark inside the string: 

var text = "I'm learning JavaScript";

or:

var text = 'He said "Hello"';

16. Boolean Values and !

JavaScript has Boolean values:

true
false

The ! operator means logical NOT.

Example

var isok = true;

alert(!isok);

Result:

false

Truthy and Falsy

JavaScript allows values of other types to be interpreted as truthy or falsy in Boolean contexts. 

var isok = 0;

alert(!isok);

Result:

true

This happens because 0 is a falsy value.

Similarly, an empty string "", null, and undefined are falsy. 

var isok = "Hello";

alert(!isok);

Result:

false

because "Hello" is truthy.

20. null and undefined

null

null represents an explicitly assigned empty/null value.

It is roughly comparable to Python's None conceptually. 

var value = null;

undefined

undefined generally indicates that a value has not been assigned. 

var value;

At this point:

value === undefined

is:

true

Important distinction

null       → intentionally represents no value
undefined  → value is absent/not assigned

21. Arrays

JavaScript arrays use square brackets: 

var a = ["Steff", "Jasson"];

Unlike traditional C arrays, JavaScript arrays can contain values of different types. 

var a = ["Hello", 10, true];

They are more similar to Python lists in this respect.

Common methods

a.push("Brian");
a.unshift("Kelly");
a.pop();
a.shift();
a.sort();

push()

Adds an element to the end:

a.push("Brian");

unshift()

Adds an element to the beginning:

a.unshift("Kelly");

pop()

Removes and returns the last element.

shift()

Removes and returns the first element.

This makes them useful for operations similar to stacks and queues.

Other methods include:

concat()
join()
pop()

22. Conditional Statements

JavaScript has conditional statements:

if
else if
else

Basic structure

if (condition) {
    // statements
}
else if (condition) {
    // statements
}
else {
    // statements
}

The condition is evaluated in a Boolean context.

It does not necessarily have to literally be true or false; JavaScript can interpret other values as truthy or falsy.

23. for Loop

Example

var sum = 0;

for (var i = 0; i < 100; i++) {
    sum = sum + i;
}

The three parts are:

for (initialization; condition; increment)

In this example:

initialization → var i = 0
condition      → i < 100
increment      → i++

24. while Loop

while (condition) {
    statement;
}

The condition is checked before each iteration.

Example

var i = 0;

while (i < 10) {
    i++;
}

The condition must eventually become false. Otherwise, the program can enter an infinite loop.

25. do...while Loop

do {
    statements;
} while (condition);

The important difference is that the statements execute at least once, because the condition is checked after the first execution.

26. Functions

A function groups statements that perform an operation.

Basic syntax

function FunctionName() {
    statement1;
    statement2;
}

Example

function myFunction() {
    alert("Using JavaScript");
}

The function can then be called: 

myFunction();

27. this

In JavaScript, this is a special keyword whose meaning depends on how the function is called.

It is commonly used to refer to the relevant object/context.

28. Document Object Model — DOM

DOM = Document Object Model

The DOM represents an HTML document as a structure of objects that JavaScript can interact with.

Example HTML

<body>
    <h1>Hello World!</h1>
</body>

The browser represents the document as a structure containing elements and objects.

JavaScript can use the DOM to:

  • Examine elements.
  • Change their content.
  • Change their state.
  • Change their styles.
  • Respond to user interaction.

29. Finding an HTML Element

A common DOM method is:

document.getElementById("myh1");

It searches for an HTML element with the specified id.

Example

<h1 id="myh1">Hello World!</h1>

Then:

const element = document.getElementById("myh1");

The variable element now refers to that DOM element.

30. Changing HTML Content

The innerHTML property can be used to change the HTML content inside an element.

Example

const element = document.getElementById("myh1");

element.innerHTML = "Hello JavaScript!";

The original:

<h1 id="myh1">Hello World!</h1>

becomes visually:

Hello JavaScript!
