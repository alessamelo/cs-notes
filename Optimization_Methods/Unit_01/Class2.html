Numerical Methods for Unconstrained Optimization

Lecture notes — iterative methods, descent directions, and optimality conditions

1. Basic Concepts of Iterative Methods

Numerical methods for solving optimization problems are usually iterative. To describe them, we define the following concepts:

  • Starting point: \(x_0\)
  • Travel direction: \(d_0\)
  • Step size: \(\alpha_0\)
Note: in an iterate, what matters is how far the initial iterate is from the next one (i.e., the step taken) — not how close that iterate is to the true (real) optimal value. The step size can be different at every iteration.

Idea Behind Optimization Numerical Methods

Given an initial guess (iterate) \(x_0\), we define a direction \(d_0\) and find a constant \(\alpha_0\) such that \(f\) is minimized as much as possible. Thus, the next iterate is computed as:

\[ x_1 = x_0 + \alpha_0 d_0 \]

To have a decrease from \(x_0\) in the direction \(d_0\), we need:

\[ \nabla f\left(x^{(0)}\right)^{\top} d_0 < 0 \]

The choice of the direction vector \(d_0\) and the step size \(\alpha_0\) differ among the known numerical methods.

Generally, these methods look for the local minimum nearest to the starting point — not necessarily the global minimum.

We can design an algorithm to compute the step size, and we could in principle also change the direction at each step — but this is not generally recommended. It is usually better to maintain a consistent strategy for the direction in a general problem. When moving from one point to the next, the function value will either increase (ascend) or decrease.

  • For minimizing, we always need a descent direction.
  • The algorithm must check the direction at each point.
  • All iterative methods require the gradient.

The direction must satisfy:

\[ \nabla f\left(x^{(0)}\right)^{\top} d_0 < 0 \quad \text{(descent condition)} \]

The direction that satisfies this condition is the negative gradient:

\[ d_0 = -\nabla f(x_0) \]

This method is called the Steepest Descent method (also called the Gradient Descent method). Different numerical methods mainly differ in how they scale (choose) the step size.

2. The Gradient Descent Method — Worked Example

Example

Given \( f = x_1^2 + 5x_2^2 \)

Initial iterate: \( x_0 = (3,1)^\top ; \; f_0 = f(x_0) = 14 \)

Gradient:

\[ \nabla f(x_1,x_2) = \begin{pmatrix} 2x_1 \\ 10x_2 \end{pmatrix} \;\rightsquigarrow\; \nabla f(x_0) = \begin{pmatrix} 6 \\ 10 \end{pmatrix} \;\rightsquigarrow\; d_0 = \begin{pmatrix} -3 \\ -5 \end{pmatrix} = -\nabla f(x_0) \]

i) Construct \(x(\alpha)\) along the direction \(d = (-3,-5)^\top = -\nabla f(x_0)\):

\[ x(\alpha) = x_0 + \alpha d_0 = (3,1) + \alpha(-3,-5) = (3 - 3\alpha,\; 1 - 5\alpha) \]

ii) Evaluate \(f\) at \(x(\alpha)\):

\[ f(x(\alpha)) = (3-3\alpha)^2 + 5(1-5\alpha)^2 = \omega(\alpha) \]

iii) To obtain the critical point, solve:

\[ \frac{d\omega(\alpha)}{d\alpha} = 0 \]

This is a minimization problem.

Solving:

\[ \omega'(\alpha) = 0 \iff 268\alpha = 68 \;\Rightarrow\; \alpha = \frac{68}{268} = 0.253731\ldots \quad \text{(exact step size)} \]

Thus, the new iterate is:

\[ x_1 = x_0 + \alpha^{*} d = \begin{pmatrix}3\\1\end{pmatrix} + 0.25373\begin{pmatrix}-3\\-5\end{pmatrix} = \begin{pmatrix}2.2388\\-0.2687\end{pmatrix} \]

and

\[ f(x_1) = (2.2388)^2 + 5(-0.2687)^2 = 5.0123 + 5(0.0718) = 5.3714 \]
Keep exact decimal numbers when reporting intermediate results (e.g., 0.253731…, 2.2388, 5.3714) rather than rounding too early.

Better methods are Newton's method and Quasi-Newton methods: they rely on the second derivative (the Hessian), have higher computational cost, but are more precise.

This steepest-descent method shows slower convergence — it can be genuinely difficult to reach the solution in a reasonable amount of time. In practice we work with functions of two or three variables. The process requires computing the gradient and evaluating it at the starting point to obtain the new direction. Whether a direction is a descent direction depends on the inner product \(\nabla f(x_k)^\top d\), and this depends on the current point. If we have a descent direction, the new point's function value is strictly less than the previous one — for example \(f(x_k) = 3.1\) while \(f(x_k + \alpha d) = 3.100002\) would not indicate descent.

3. Descent Direction

Definition: A direction \(d\) from which we want to minimize a function, departing from a given iterate \(\bar{x}_0\), is called a descent direction if and only if:

\[ \nabla f(x_0)^{\top} d < 0 \qquad (\ast) \]

Setting \(d = -\nabla f(x_0)\) determines the gradient descent method (also called the steepest descent method).

Example

\( f(x_1,x_2) = x_1 x_2^2 ; \quad x^{(0)} = [1,2] \)

\[ \nabla f(x_1,x_2) = (x_2^2,\; 2x_1x_2) \;\rightsquigarrow\; d_{sd}(1,2) = (-4,-4) \]

Is \([-1,2]\) a descent direction?

\[ (4,4)\begin{pmatrix}-1\\2\end{pmatrix} = 4 > 0 \quad \text{No!} \]
\[ (4,4)\begin{pmatrix}-1\\1/2\end{pmatrix} = -2 < 0 \quad \text{Yes!} \]

Step Size (\(\alpha > 0\))

How far should we advance in direction \(d\) such that:

\[ f(x_k + \alpha d) < f(x_k) \]

4. Numerical Optimization — General Framework

Numerical optimization is part of applied mathematics used to determine the best solution to problems that arise in real situations. It involves the study of optimality conditions, and the analysis and computational implementation of methods for solving real-life problems.

Recall: \(\min f(x) \equiv \max -f(x)\)

Unconstrained optimization:

\[ \text{find } x^{*} \in \mathbb{R}^n \quad \text{s.t.} \quad f(x^{*}) \leq f(x) \quad \forall x \in \mathbb{R}^n \]

Local Minimizer versus Global Minimizer

Example: \( f(x) = 3x^4 - 4x^3 \) on the closed interval \([-1, 2]\).

(Sketch: the function has a local minimum near the start of the interval and a global minimum elsewhere on \([-1,2]\); having a constrained (bounded) domain makes the problem harder, since we must also check the endpoints of the interval.)

Constrained Problem Example

\( f(x) = 3x^4 - 4x^3 \) on the closed interval \([-1, 2]\)

First order condition:

\[ f'(x) = 12x^3 - 12x^2 = 12x^2(x-1) \]
\[ f'(x) = 0 \iff x = 0, \; x = 1 \quad \text{(critical points)} \]

Second order condition:

\[ f''(x) = 36x^2 - 24x = x(36x - 24) \]
\[ x = 0 \;\rightarrow\; f''(0) = 0 \quad \text{Saddle point} \]
\[ x = 1 \;\rightarrow\; f''(1) = 12 > 0 \quad \text{minimizer on } [-1,2] \]
A saddle point is a point where the function changes concavity/direction; it occurs when the second derivative is 0. In constrained problems we must always respect the given restrictions (interval bounds) — some students make mistakes by ignoring the interval endpoints when checking for global extrema.

Weak / Strong / Global Minima — Definitions

For a scalar function \( f(x) : \mathbb{R}^n \to \mathbb{R} \):

ConditionType of minimum
\(\exists\, \delta > 0\) such that \(f(x^{*}) \leq f(x)\) if \(\|x - x^{*}\| < \delta\) Weak local minimum
\(\exists\, \delta > 0\) such that \(f(x^{*}) < f(x)\) if \(\|x - x^{*}\| < \delta\) Strong local minimum
If \(f(x^{*}) \leq f(x)\) \(\forall x \in \mathbb{R}^n\) \(x^{*}\) is a Global minimum

5. Second-Order Conditions and the Hessian Matrix

If \(\nabla f(x^{*}) = 0\), then \(x^{*}\) is just a critical point. To determine whether it is a minimizer, we additionally need one of the following equivalent conditions:

i) \(\forall\, y \in \mathbb{R}^n : y^{\top} \nabla^2 f(x^{*})\, y \geq 0\)

ii) All eigenvalues of \(\nabla^2 f(x^{*})\) are positive

The Hessian matrix, \(\nabla^2 f(x)\), is the matrix of second-order partial derivatives of \(f\). For \(f(x_1, x_2)\), the gradient \(\nabla f\) is a vector, \(\nabla f(x) = 0\) defines a (generally linear or nonlinear) system, and the Hessian \(H(x)\) is a matrix.

Example

\( f(\vec{x}) = 2x_1^2 + 8x_2^2 + 8x_1x_2 - 5x_1 \)

First order conditions (necessary conditions):

\[ \frac{\partial f}{\partial x_1} = 4x_1 + 8x_2 - 5 = 0 \] \[ \frac{\partial f}{\partial x_2} = 16x_2 + 8x_1 = 0 \]

Which is equivalent to the linear system:

\[ -8x_1 - 16x_2 = -10 \]\[ 8x_1 + 16x_2 = 0 \]

In this case, there is no critical point (the domain is unbounded), and therefore the function does not have optimal values.

Convexity

A set \( S \subseteq \mathbb{R}^n \) is convex if, for every pair of vectors \(\vec{x}, \vec{y} \in S\) and every real number \(\alpha\), \(0 < \alpha < 1\), the convex combination \(\alpha x + (1-\alpha) y \in S\).

In other words: the line segment joining any two points of \(S\) lies entirely inside \(S\).

The function \(f(x)\), defined over the convex set \(S\), is called a convex function if, for every pair of points \(x, y \in S\):

\[ f(\alpha x + (1-\alpha)y) \;\leq\; \alpha f(x) + (1-\alpha) f(y) \]

This inequality is called the convexity condition (convex combination inequality) for \(x\) and \(y\). If all eigenvalues of the Hessian are positive everywhere, then \(f(x)\) is convex.

6. Finding a Global Minimum/Maximum on a Closed Interval

Example

Find the global minimum/maximum of \( f(x) = 3x^2 - 18x + 5 \) on \([0, 7]\).

1) \( f'(x) = 6x - 18 \)

2) \( f'(x) = 0 \iff 6x - 18 = 0 \equiv x - 3 = 0 \Rightarrow x = 3 \)

3) Evaluate critical points and interval endpoints:

\[ f(3) = 27 - 54 + 5 = -22 \]
\[ f(0) = 5, \qquad f(7) = 3 \times 49 - 18 \times 7 + 5 = 147 - 126 + 5 = 26 \]

Thus, the absolute minimum is at \(x = 3\), and the absolute maximum is at \(x = 7\).

7. The Conjugate Gradient Method (for Quadratic Functions)

Note: unlike steepest descent, the conjugate gradient method updates the search direction using a combination of the current residual and the previous direction (via \(\beta_k\)), which improves convergence for quadratic problems.

r0 := b - A x0
if r0 is sufficiently small, then return x0 as the result
p0 := r0
k := 0

repeat
    alpha_k := (r_k^T r_k) / (p_k^T A p_k)
    x_{k+1} := x_k + alpha_k * p_k
    r_{k+1} := r_k - alpha_k * A p_k
    if r_{k+1} is sufficiently small, then exit loop

    beta_k := (r_{k+1}^T r_{k+1}) / (r_k^T r_k)
    p_{k+1} := r_{k+1} + beta_k * p_k
    k := k + 1
end repeat

return x_{k+1} as the result

For comparison, the Steepest Descent method (shown earlier) uses \(d_0 = -\nabla f(x_0)\) directly as the search direction at every step, without the conjugate-direction correction term \(\beta_k p_k\).
