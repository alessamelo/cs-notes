1. Constrained Problems

We can use level curves as constraints or simple intervals.

Example: Ellipse as a Constraint

An ellipse can represent a constraint in an optimization problem.

2. Level Curves and Optimization

By moving the level curves, one of them will eventually touch the constraint.

At the point where the level curve touches the constraint, the two curves are tangent.

This idea leads to the use of Lagrange multipliers.

3. Lagrange Multipliers

In a constrained optimization problem, we have an objective function f and a constraint function g.

f = objective function to optimize

g = constraint function

The main Lagrange multiplier condition is: 

∇f = λ∇g

Here, the gradient of the objective function depends on the constraint through the Lagrange multiplier λ.

This is called the method of Lagrange multipliers.

If the professor changes the constraint from an ellipse to a circle, the method does not change. Only the function g changes to represent the circle.

4. Lagrange Problem

The general constrained problem can be represented as: 

Optimize f(x,y)

subject to

g(x,y) = c

The Lagrange equations are: 

fx(x,y) = λ gx(x,y)

fy(x,y) = λ gy(x,y)

g(x,y) = c

5. Tangency of Two Curves

Two curves are tangent at a point when their gradients are parallel at that point. 

∇f = λ∇g

Therefore, the Lagrange multiplier condition expresses the tangency between the level curve of the objective function and the constraint.

6. Example: Lagrange Multipliers

Consider:

f(x,y) = 4xy

with the constraint:

g(x,y) = x² / 9 + y² / 16 = 1

We try to maximize the objective function according to the restriction.

The Lagrange system is:

fx(x,y) = λ gx(x,y)

fy(x,y) = λ gy(x,y)

g(x,y) = 1

7. Level Curves as a Minimization Problem

The level curves represent different values of the objective function. By moving these curves, we can obtain a minimizing or maximizing problem subject to the constraint.

The objective is to find the point where the appropriate level curve touches the constraint.

8. Box Dimensions and Lagrange Multipliers

Some problems require finding the dimensions of a box. These can be modeled using the Lagrange multiplier method.

The problem should first be modeled mathematically and then solved by hand using the Lagrange equations.

Exam note:

Problems that the professor asks us to solve will include the model problem itself, not only the minimization expression.

9. Key Concepts for Unconstrained Optimization

A differentiable function can reach a minimum at a critical point.

The first derivative in several variables is represented by the gradient: 

∇f(x,y)

We find critical points by solving: 

∇f(x,y) = 0

Then we use the Hessian to evaluate the critical points.

Hessian Classification

Hessian Classification
H > 0 Symmetric and positive definite
H < 0 Symmetric and negative definite
H is indefinite Neither positive nor negative definite

10. Example: Function Without a Derivative

Consider:

f(x) = |x - 3|

This function does not have a derivative at x = 3.

However, it has a minimum at: 

x = 3

Graph of f(x) = |x - 3|

11. Example: Critical Point That Is Not a Minimum or Maximum

Consider:

f(x) = 3x⁵ - 1

First derivative

f'(x) = 15x⁴

Critical point:

x = 0

Second derivative

f''(x) = 60x³

At the critical point:

f''(0) = 0

Therefore, the second derivative test does not classify x = 0 as a maximum or minimum.

It is an inflexion point.

Key idea:

The first derivative being zero is only a necessary condition for a differentiable local optimum. It does not by itself determine whether a point is a minimum or maximum.

12. Local and Absolute Maximizer

Absolute maximizer

If: 

f(x*) ≥ f(x)  for all x ∈ Rⁿ

then x* is an absolute maximizer.

Maximizer on an interval

If: 

f(x*) ≥ f(x)  for x ∈ [a,b]

then x* is a maximizer on the interval.

If f(x) is continuous on [a,b], it reaches its maximum and minimum on that interval.

13. Example: Indefinite Hessian

Consider:

f(x₁, x₂) = x₁x₂

Gradient

∇f = (x₂, x₁)

Critical point:

(0,0)

Hessian

H = | 0  1 |
    | 1  0 |

The eigenvalues are: 

λ₁ = -1
λ₂ =  1

Since the Hessian has both a positive and a negative eigenvalue, it is indefinite.

Therefore, the critical point is not a local minimum or maximum.

14. Convex Functions

A function is convex if it satisfies the convexity inequality: 

f(λx₁ + (1 - λ)x₂)
≤
λf(x₁) + (1 - λ)f(x₂)

where: 

0 ≤ λ ≤ 1

Geometrically, the line segment between two points on the function lies above or on the graph of the function.

The function discussed in the notes is not convex because the line traced between certain points ends up outside the required region.

It is also not concave.

15. Exam Example: Two Positive Integers

Problem:

Find two positive integer numbers such that their sum is 25 and 2x₁² + 3x₂² is minimum.

Mathematical Model

Objective:

min f(x₁,x₂) = 2x₁² + 3x₂²

Subject to:

x₁ + x₂ = 25

16. Variable Substitution

From the constraint: 

x₂ = 25 - x₁

Substitute this into the objective function: 

min f(x₁)
= 2x₁² + 3(25 - x₁)²

The variable substitution converts the constrained problem into an unconstrained one-variable problem.

17. First Derivative

Calculate the derivative and set it equal to zero. 

f'(x₁) = 0

This gives: 

x₁ = 15

Replace this value in the constraint: 

x₂ = 25 - 15

x₂ = 10

Therefore, the solution is: 

(x₁, x₂) = (15, 10)

18. Second Derivative

The second derivative is: 

f''(x₁) = 10

Since the second derivative is positive, this critical point is a minimum.

19. Why the Constraint Matters

If we ignore the variable substitution and only calculate the gradient and Hessian of the original objective function, we can obtain information about the existence of a minimum.

However, this does not solve the exact constrained problem because the constraint has not been considered.

The optimization problem is not simply: 

min 2x₁² + 3x₂²

It is: 

min 2x₁² + 3x₂²

subject to

x₁ + x₂ = 25

The restriction determines which points are allowed as solutions.

Key Ideas to Remember

  • A constrained optimization problem includes an objective function and one or more constraints.
  • Lagrange multipliers use: ∇f = λ∇g.
  • At a tangency point, the gradients of the two curves are parallel.
  • Changing an elliptical constraint to a circular constraint does not change the Lagrange method; only g changes.
  • A zero gradient identifies a critical point, but does not by itself prove that the point is a minimum or maximum.
  • The Hessian helps classify critical points.
  • A critical point can be an inflection point rather than an optimum.
  • Constraints must be included when solving constrained optimization problems.
  • A constrained problem can sometimes be converted into an unconstrained problem through variable substitution.
