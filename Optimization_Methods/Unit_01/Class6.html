1. Lagrange Multiplier Theorem

Let \(f\) and \(g\) have continuous first partial derivatives. Suppose that \(f\) has a local maximum or minimum at a point \((x_0,y_0)\) subject to the smooth constraint:

\[ g(x,y)=c \]

and suppose:

\[ \nabla g(x_0,y_0)\neq 0. \]

Then there exists a number \(\lambda\), called the Lagrange multiplier, such that:

\[ \boxed{ \nabla f(x_0,y_0)=\lambda \nabla g(x_0,y_0) } \]

This means that, at a constrained extreme point, the gradients of \(f\) and \(g\) are parallel.

Lagrange Multiplier System

In two variables, the Lagrange multiplier equation produces the following system:

\[ \boxed{ f_x(x,y)=\lambda g_x(x,y) } \]
\[ \boxed{ f_y(x,y)=\lambda g_y(x,y) } \]

Together with the constraint:

\[ \boxed{ g(x,y)=c } \]

Geometric Interpretation

The level curve of \(f\) touches the constraint curve at the maximum or minimum point.

For example, if the constraint is:

\[ \frac{x^2}{9}+\frac{y^2}{16}=1, \]

the constraint is an ellipse. At an extreme value, a level curve of \(f\) is tangent to this ellipse.

Example: Absolute Maximum and Minimum

Find the absolute maximum and minimum of:

\[ f(x,y)=x^2+y^2-x-y \]

on the region:

\[ D=\{(x,y):x^2+y^2\leq 1\}. \]

Because \(D\) is a closed and bounded region and \(f\) is continuous, the Extreme Value Theorem guarantees that \(f\) has an absolute maximum and an absolute minimum on \(D\).

We must examine:

  1. Critical points inside \(D\).
  2. Points on the boundary of \(D\).

Step 1: Find Critical Points Inside the Region

Calculate the gradient:

\[ \nabla f(x,y)= \left( \frac{\partial f}{\partial x}, \frac{\partial f}{\partial y} \right) \]

The partial derivatives are:

\[ f_x=2x-1 \]
\[ f_y=2y-1. \]

For a critical point:

\[ \nabla f=0. \]

Therefore:

\[ 2x-1=0 \]

and:

\[ 2y-1=0. \]

Thus:

\[ \boxed{ x=\frac12, \qquad y=\frac12 } \]

Therefore, the interior critical point is:

\[ \boxed{ \left( \frac12, \frac12 \right) } \]

We verify that this point belongs to \(D\):

\[ \left(\frac12\right)^2+ \left(\frac12\right)^2 = \frac14+\frac14 = \frac12<1. \]

Therefore, the critical point is inside the region.

Now evaluate \(f\):

\[ f\left( \frac12, \frac12 \right) = \left(\frac12\right)^2+ \left(\frac12\right)^2 - \frac12- \frac12 \]
\[ = \frac14+ \frac14 - 1 = \boxed{-\frac12}. \]

Step 2: Analyze the Boundary

The boundary of \(D\) is:

\[ x^2+y^2=1. \]

This is the unit circle.

Since there is one equation and two variables, we can parametrize the boundary.

\[ x(t)=\cos t \]
\[ y(t)=\sin t \]

where:

\[ 0\leq t\leq2\pi. \]

Therefore:

\[ \mathbf{b}(t) = (\cos t,\sin t). \]

Substitute the parametrization into \(f\):

\[ f(\cos t,\sin t) = \cos^2t+ \sin^2t- \cos t- \sin t. \]

Using the identity:

\[ \cos^2t+\sin^2t=1, \]

we obtain:

\[ h(t)=1-\cos t-\sin t. \]

Step 3: Differentiate

Differentiate \(h(t)\):

\[ h'(t)=\sin t-\cos t. \]

Set the derivative equal to zero:

\[ \sin t-\cos t=0. \]

Therefore:

\[ \sin t=\cos t. \]

Thus:

\[ \tan t=1. \]

On the interval \([0,2\pi]\), the solutions are:

\[ \boxed{ t=\frac{\pi}{4} } \]

and:

\[ \boxed{ t=\frac{5\pi}{4} } \]

Step 4: Evaluate the Boundary Candidates

Candidate 1: \(t=\frac{\pi}{4}\)

\[ \cos\frac{\pi}{4} = \sin\frac{\pi}{4} = \frac{\sqrt2}{2}. \]

The corresponding point is:

\[ \boxed{ \left( \frac{\sqrt2}{2}, \frac{\sqrt2}{2} \right) }. \]

Evaluate the function:

\[ h\left( \frac{\pi}{4} \right) = 1- \frac{\sqrt2}{2} - \frac{\sqrt2}{2} \]
\[ = \boxed{ 1-\sqrt2 }. \]

Candidate 2: \(t=\frac{5\pi}{4}\)

\[ \cos\frac{5\pi}{4} = -\frac{\sqrt2}{2} \]
\[ \sin\frac{5\pi}{4} = -\frac{\sqrt2}{2}. \]

The corresponding point is:

\[ \boxed{ \left( -\frac{\sqrt2}{2}, -\frac{\sqrt2}{2} \right) }. \]

Evaluate:

\[ h\left( \frac{5\pi}{4} \right) = 1+ \frac{\sqrt2}{2} + \frac{\sqrt2}{2} \]
\[ = \boxed{ 1+\sqrt2 }. \]

Step 5: Compare All Candidates

Point Function Value
\( \left( \frac12, \frac12 \right) \) \( -\frac12 \)
\( \left( \frac{\sqrt2}{2}, \frac{\sqrt2}{2} \right) \) \( 1-\sqrt2 \)
\( \left( -\frac{\sqrt2}{2}, -\frac{\sqrt2}{2} \right) \) \( 1+\sqrt2 \)

Numerically:

\[ -\frac12=-0.5 \]
\[ 1-\sqrt2\approx-0.414 \]
\[ 1+\sqrt2\approx2.414. \]

Final Answer

The absolute minimum is:

\[ \boxed{ \text{Absolute minimum} = -\frac12 } \]

at the point:

\[ \boxed{ \left( \frac12, \frac12 \right) }. \]

The absolute maximum is:

\[ \boxed{ \text{Absolute maximum} = 1+\sqrt2 } \]

at the point:

\[ \boxed{ \left( -\frac{\sqrt2}{2}, -\frac{\sqrt2}{2} \right) }. \]

Important Procedure

For absolute optimization on a closed and bounded region, the general procedure is:

\[ \boxed{ \text{Interior Critical Points} \quad+\quad \text{Boundary Points} \quad\longrightarrow\quad \text{Compare All Function Values} } \]

The second derivative test can classify an unconstrained critical point. However, for an absolute optimization problem on a constrained closed region, examining the boundary is essential.
