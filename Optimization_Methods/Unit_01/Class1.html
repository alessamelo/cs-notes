Optimization Methods

Course notes on optimization, numerical optimization, problem classification, convergence, and numerical methods.

1. Optimization

Optimization is the study of finding the optimal points of a function or model.

The objective is usually to find:

  • Maximum: the largest possible value of the objective function.
  • Minimum: the smallest possible value of the objective function.

Optimization can be applied to mathematical models that represent real-world problems.

TC — Teacher Commentary: We are solving problems while communicating with the client. The mathematical model must represent the real problem and its requirements.

2. Numerical Optimization

Numerical optimization is a part of applied mathematics that uses numerical methods to determine good or optimal solutions to problems arising from models of real situations.

Mathematical Model

A model is an abstraction of a real-world problem. It represents the relevant characteristics of the real situation using mathematical concepts such as variables, functions, objectives, and constraints.

TC — Teacher Commentary: The purpose of the course is not only to solve optimization problems, but also to understand which numerical method is appropriate for a specific problem.

3. Mathematical vs. Numerical Problem Solving

Optimization problems can be solved analytically or numerically.

Analytical / Mathematical Solution

A mathematical or analytical method attempts to obtain an exact solution using mathematical operations and derivations.

For example, for an unconstrained differentiable function, critical points can be found by solving:

f'(x) = 0

Numerical Solution

Numerical methods approximate a solution through a sequence of calculations. They are especially useful when an exact analytical solution is difficult or impossible to obtain.

TC — Required distinction: The course focuses on understanding the difference between solving a problem mathematically and solving it using numerical methods.

4. Classification of Optimization Problems

Optimization problems can be classified according to several characteristics.

4.1 Objectives

  • Single-objective: one objective function is optimized.
  • Multi-objective: multiple objectives must be considered simultaneously.

The objective may depend on one variable or many variables.

4.2 Variables

  • Continuous variables: can take values in a continuous interval.
  • Integer variables: must take integer values.
  • Mixed variables: contain both continuous and integer variables.

4.3 Constraints

  • Unconstrained optimization: there are no restrictions imposed on the variables.
  • Constrained optimization: the solution must satisfy one or more restrictions.

4.4 Landscape

  • Convex: the structure of the objective function allows optimization methods to identify a global optimum under appropriate conditions.
  • Non-convex: the function can contain multiple local minima or maxima, making the global optimum more difficult to find.

4.5 Techniques

  • Exact methods: seek an exact or mathematically guaranteed solution.
  • Approximate / numerical methods: obtain an approximation to the solution using iterative calculations.

5. Convex and Non-Convex Functions

Convex

A function is convex when its graph has a shape in which the line segment connecting two points on the graph lies on or above the graph.

Informally, a convex function has a "bowl-like" shape when performing minimization.

Non-Convex

A non-convex function does not satisfy the convexity property. Its landscape can contain several local minima and maxima.

Therefore, finding a local optimum does not necessarily mean that the global optimum has been found.

6. Convergence

In numerical optimization, an iterative method normally generates a sequence of approximations:

x(0), x(1), x(2), ...

Convergence occurs when the sequence of approximations approaches the desired solution.

Convergence Criterion

A common way to measure the change between two consecutive iterations is:

||x(k) − x(k−1)||

When this value becomes sufficiently small, the algorithm can consider the solution to have converged.

A tolerance can be defined as:

||x(k) − x(k−1)|| < ε

where ε is a predefined tolerance.

7. Example: Finding an Optimum

Consider the function:

f(x) = 3x3 + 2x − 3

Suppose we want to minimize this function.

Step 1 — Calculate the Derivative

The first derivative is:

f'(x) = 9x2 + 2

Step 2 — Find Critical Points

Critical points are obtained by solving:

f'(x) = 0

Therefore:

9x2 + 2 = 0

This gives:

x2 = −2/9

There are no real solutions because the square of a real number cannot be negative.

Conclusion

The function has no real critical points. In addition, because the cubic term dominates for large positive and negative values of x, the function is unbounded below and therefore has no global minimum over ℝ.

Important: Finding f'(x) = 0 is a way of identifying possible critical points. It does not automatically mean that a minimum exists.

8. Numerical Methods

Several numerical methods can be used to solve mathematical problems that appear inside optimization algorithms.

8.1 Newton's Method

Newton's method is an iterative numerical method used to find a root of a nonlinear equation:

f(x) = 0

The classical update is:

xk+1 = xk − f(xk) / f'(xk)

In optimization, Newton's method can also be applied to the first derivative of an objective function to search for stationary points.

For example, to find a stationary point:

f'(x) = 0

Newton's method can be applied to the function g(x) = f'(x).

8.2 Gaussian Elimination

Gaussian elimination is a numerical method for solving systems of linear equations.

A system can be represented as:

Ax = b

The method transforms the system into an equivalent triangular form and then uses back substitution to obtain the solution.

Gaussian elimination is particularly important because many optimization algorithms require solving linear systems.

8.3 Jacobi Method

The Jacobi method is an iterative method for solving systems of linear equations:

Ax = b

Instead of solving the system directly, the method starts from an initial approximation and repeatedly calculates improved approximations.

The method can be useful for large systems when an iterative solution is preferable to direct elimination.

9. Important Distinction: Root Finding vs. Optimization

Newton, Gaussian, and Jacobi methods should not be confused with optimization algorithms.

Method Main Purpose Typical Problem
Newton Find a root or solve nonlinear equations f(x) = 0
Gaussian Elimination Solve a linear system Ax = b
Jacobi Iteratively solve a linear system Ax = b

These methods are often components of larger optimization procedures, but they do not automatically minimize or maximize an arbitrary function.

10. Key Ideas to Remember

  • Optimization searches for maximum or minimum values.
  • A model is an abstraction of a real-world problem.
  • Numerical optimization uses numerical procedures to approximate solutions.
  • Optimization problems can be classified by objectives, variables, constraints, landscape, and solution technique.
  • A constrained problem has restrictions on the feasible solutions.
  • An unconstrained problem has no explicit restrictions on the variables.
  • Convex problems generally have more favorable optimization properties than non-convex problems.
  • Convergence means that successive approximations approach a solution.
  • The quantity ||x(k) − x(k−1)|| can measure the change between iterations.
  • Solving f'(x) = 0 identifies candidate stationary points, but additional analysis is required to determine whether they are minima, maxima, or neither.
  • Newton's method finds roots and can be incorporated into optimization.
  • Gaussian elimination and Jacobi solve systems of linear equations and can appear as computational components of optimization algorithms.
