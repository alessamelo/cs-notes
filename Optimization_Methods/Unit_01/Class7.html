1. Possible Exam Ideas

Question Type: Given a Function, Invent a Descent Direction

Given an objective function \(f(x)\), determine a valid descent direction at a given point.

A vector \(d\) is a descent direction at \(x\) if:

\[ \nabla f(x)^T d < 0. \]

The most common descent direction is the negative gradient:

\[ \boxed{ d=-\nabla f(x) } \]

because:

\[ \nabla f(x)^T(-\nabla f(x)) = -\|\nabla f(x)\|^2<0 \]

whenever:

\[ \nabla f(x)\neq0. \]

Descent Iterative Methods

Descent iterative methods move step by step using local information. Depending on the function and the step size, their trajectory can exhibit zigzag behavior.

They usually converge to a local minimum determined by the initial point and its basin of attraction rather than explicitly searching all possible extrema.

Unlike the manual method for constrained optimization, a basic iterative descent method does not separately calculate interior critical points and boundary critical points.

To solve constrained problems, the constraints must be incorporated into the iterative algorithm using techniques such as:

  • Projection methods
  • Penalty methods
  • Barrier methods
  • Lagrange multiplier methods

4. Lagrange Multipliers

For a constrained optimization problem:

\[ \min/\max f(x,y) \]

subject to:

\[ g(x,y)=c, \]

the Lagrange condition is:

\[ \boxed{ \nabla f(x,y) = \lambda\nabla g(x,y) } \]

together with:

\[ \boxed{ g(x,y)=c } \]

5. Hessian Matrix Analysis

For a function \(f(x_1,x_2)\), the Hessian matrix is:

\[ H_f(x)= \begin{pmatrix} \frac{\partial^2f}{\partial x_1^2} & \frac{\partial^2f}{\partial x_1\partial x_2} \\ \frac{\partial^2f}{\partial x_2\partial x_1} & \frac{\partial^2f}{\partial x_2^2} \end{pmatrix}. \]

Classification

Hessian Condition Conclusion
Positive Definite Strict Local Minimum
Negative Definite Strict Local Maximum
Indefinite Saddle Point
Semidefinite Test is Inconclusive

At a stationary point \(x^*\), the first-order necessary condition is:

\[ \boxed{ \nabla f(x^*)=0 } \]

The Hessian is then used to classify the stationary point.

6. Previous Quiz: Absolute Minimum

A possible question is:

Find the Absolute Minimum

Given a function and a domain, determine the absolute minimum.

The general procedure is:

  1. Calculate the gradient.
  2. Find all stationary points inside the domain.
  3. Check whether each stationary point belongs to the domain.
  4. Analyze the boundary if the domain is closed.
  5. Evaluate the function at every candidate point.
  6. Compare all values.
\[ \boxed{ \text{Interior candidates} + \text{Boundary candidates} \rightarrow \text{Compare function values} } \]

7. Rectangular Box Optimization Problem

Problem

Construct a rectangular box without a lid using \(2d\text{ m}^2\) of material, where \(d=8\), such that the volume is maximized.

The questions are:

  1. Describe and model the problem as a constrained optimization problem.
  2. Solve the problem as an unconstrained optimization problem by eliminating one of the variables.

Model

Suppose the dimensions of the rectangular box are:

  • Length: \(x\)
  • Width: \(y\)
  • Height: \(z\)

The volume is:

\[ V(x,y,z)=xyz. \]

Since the box has no lid, the material constraint consists of the bottom and four lateral sides:

\[ xy+2xz+2yz=2d. \]

Since \(d=8\):

\[ xy+2xz+2yz=16. \]

Constrained Optimization Form

\[ \boxed{ \max xyz } \]

subject to:

\[ \boxed{ xy+2xz+2yz=16. } \]

Unconstrained Approach

Solve the constraint equation for one variable, for example \(z\):

\[ z= \frac{16-xy}{2x+2y}. \]

Substitute this expression into the volume function:

\[ V(x,y) = xy \left( \frac{16-xy}{2x+2y} \right). \]

The problem has now been converted into an unconstrained optimization problem in two variables.

8. Trapezium Perimeter Problem

Consider the formula expressing the perimeter of a trapezium in terms of its sides \(x\) and \(y\):

\[ P(x,y) = x+y+ \sqrt{ \frac{4A}{x+y} }. \]

Use the Steepest Descent Method to find the values of \(x\) and \(y\) that minimize \(P\).

Take:

\[ A=\frac{1}{d}. \]

Describe each step of the algorithm.

Steepest Descent General Procedure

Choose an initial point:

\[ x_0= \begin{pmatrix} x_0\\ y_0 \end{pmatrix}. \]

Calculate the gradient:

\[ \nabla P(x_k,y_k). \]

The steepest descent direction is:

\[ \boxed{ d_k= -\nabla P(x_k,y_k) } \]

Choose a step size \(\alpha_k\):

\[ \alpha_k>0. \]

Update the variables:

\[ \boxed{ x_{k+1} = x_k+\alpha_kd_k } \]

Stop when the gradient norm is sufficiently small:

\[ \boxed{ \|\nabla P(x_k)\| < \varepsilon } \]

10. Stationary Points and Second-Order Conditions

For each function, determine all stationary points and verify whether they are strict local minima using second-order sufficient conditions.

Function 1

\[ f(x_1,x_2) = 3x_1 + \frac{100}{x_1x_2} + 5x_2^2. \]

Required procedure:

  1. Calculate \(\nabla f(x_1,x_2)\).
  2. Solve: \[ \nabla f(x_1,x_2)=0. \]
  3. Find all stationary points.
  4. Calculate the Hessian matrix.
  5. Evaluate the Hessian at each stationary point.
  6. Determine whether the Hessian is positive definite.
  7. If positive definite, conclude that the point is a strict local minimum.

Function 2

\[ f(x_1,x_2) = (x_1-10)^2 + x_1x_2 + (x_2^2-1)^2. \]

Required procedure:

  1. Calculate the gradient.
  2. Find all stationary points.
  3. Calculate the Hessian.
  4. Analyze the Hessian at each stationary point.
  5. Determine whether each point is a strict local minimum, maximum, or saddle point.

  • Understand descent directions.
  • Understand why \(-\nabla f(x)\) is a descent direction.
  • Implement Steepest Descent.
  • Implement Newton's Method.
  • Implement Conjugate Gradient.
  • Choose stopping criteria.
  • Calculate gradient norms.
  • Interpret convergence.
  • Understand the influence of the initial point.
  • Recognize zigzag behavior.
  • Understand how constraints are incorporated into iterative methods.

Key Concept for the Exam

\[ \boxed{ \text{Analytical optimization} \rightarrow \text{Find and compare all mathematical candidates} } \]
\[ \boxed{ \text{Iterative optimization} \rightarrow \text{Generate a sequence approaching a solution} } \]

For constrained problems, a standard unconstrained iterative method cannot simply ignore the feasible region. The constraint must be incorporated using projection, penalties, barriers, Lagrange multiplier techniques, or other constrained optimization algorithms.
