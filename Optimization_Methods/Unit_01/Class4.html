1. Unconstrained Numerical Methods

Optimization problems can be solved using numerical methods, especially when an analytical solution is difficult or impossible to obtain.

Real-World Problem: Best Design

Consider a residential area where we need to determine the number of pipes required to cover the maximum possible number of houses.

A useful relationship is:

If the diameter of a pipe is doubled, its capacity increases by a factor of 4.

Therefore, the number of houses that a pipe can serve depends strongly on the diameter of the pipe. This type of relationship can be incorporated into an optimization problem to determine the best design.

2. Hessian Matrix and Positive Definiteness

One way to construct a positive definite matrix is to generate a random matrix A and calculate:

H = ATA

The matrix H can be used as a Hessian matrix. We can examine its eigenvalues:

eigen(H)

If all eigenvalues of the Hessian matrix are positive, then the Hessian is positive definite.

A positive definite Hessian indicates that the function is locally strictly convex around the point being analyzed.

3. First and Second Derivatives

When we calculate the first derivative of an objective function and solve:

∇G(x) = 0

we find the critical points.

However, finding a critical point does not tell us whether it is a minimum, maximum, or saddle point.

To classify the critical point, we examine the second derivative, or more generally, the Hessian matrix.

  • Positive definite Hessian: local minimum.
  • Negative definite Hessian: local maximum.
  • Indefinite Hessian: saddle point.

4. Steepest Descent Method

The steepest descent method is an unconstrained numerical optimization method used to minimize a function.

Initial Parameters

function steepest()

    x = 2;
    y = 1;
    iter = 0;

    alpha = 0.1;
    tol = 1.0e-6;
    max_iter = 100;

Objective Function

Consider the function:

F(x,y) = x² + 2y²

In MATLAB, this can be represented as: 

F = @(x,y) x^2 + 2*y^2;

Contour Plot

To visualize the function, we create a grid of values for x and y: 

[xm, ym] = meshgrid(-3:0.1:3, -3:0.1:3);

zm = xm.^2 + 2*ym.^2;

contour(xm, ym, zm);

The contour plot shows the level curves of the function. Since F(x,y) = x² + 2y² is an elliptical bowl, its minimum occurs at:

(x, y) = (0, 0)

Steepest Descent Idea

At each iteration, the algorithm moves in the direction opposite to the gradient:

xk+1 = xk − α∇F(xk)

where α is the step size and ∇F is the gradient of the objective function.
