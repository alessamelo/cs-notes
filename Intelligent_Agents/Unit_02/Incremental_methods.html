Incremental Update

In Monte Carlo methods, to update the values, we normally need to finish the entire episode.

An incremental update allows estimates to be updated progressively as new data becomes available.

Advantages

  • Possibility of faster convergence.
  • Better memory efficiency.
  • Ability to update estimates in real time as new data becomes available.

General Incremental Update Formula

The general formula is:

New Estimate = Old Estimate + Step Size × (Target − Old Estimate)

  • Old estimate: The previous estimate.
  • Step size: A small positive constant that determines the size of the update.
  • Target: The new sample value used to update the estimate.

Monte Carlo Incremental Update for V

The incremental update for the state-value function can be written as:

Vπ(St) ← Vπ(St) + &frac1;N(St) [Gt − Vπ(St)]

Where:

  • Vπ(St): Current estimate of the value of state St.
  • N(St): Number of times the state has been visited.
  • Gt: Return obtained from time t.

Monte Carlo Policy Evaluation for Qπ

The incremental update for the action-value function is:

Qπ(St, At) ← Qπ(St, At) + &frac1;N(St, At) [Gt − Qπ(St, At)]

Problem with the Previous Algorithm

The previous algorithm checked in the last class used V to calculate Q.

However, the implementation also used a probability matrix. This creates a problem because Monte Carlo policy evaluation is intended to be model-free.

The value function V cannot directly provide the required Q-values for a model-free implementation.

Therefore, for the new implementation, Q-values should be calculated directly from experience using the incremental update.

Temporal Difference Learning

Temporal Difference (TD) learning is called "temporal difference" learning because the agent updates its estimates based on the difference between estimates at different time steps.

One-Step Look-Ahead

TD learning uses a one-step look-ahead. The agent updates the estimated value of a state after receiving:

  • The immediate reward Rt+1.
  • The successor state St+1.

The basic experience can be represented as:

(St, At, Rt+1, St+1)

How TD Learning Works

For every state, the agent maintains an estimate of how good that state is. When the agent transitions to a new state and receives a reward, it uses the value estimate of the next state to adjust the estimate of the current state.

TD learning is model-free. Algorithms such as Q-learning and SARSA build upon this principle.

Monte Carlo vs. Temporal Difference

Monte Carlo

In Monte Carlo learning, the agent must wait until the episode finishes before calculating the return and updating the estimate.

Analogy: Imagine estimating how long it will take to arrive home. One approach is to wait until you arrive home and then adjust your estimate.

Temporal Difference

TD learning updates the estimate during the episode. The agent does not need to wait until the final outcome.

Using the same analogy, instead of waiting until arriving home, you continuously update your estimate during the trip based on how far you have traveled and your current estimate of the remaining travel time.

TD Learning Update Formula

The basic TD(0) update is:

V(St) ← V(St) + α[ Rt+1 + γV(St+1) − V(St) ]

Where:

  • V(St): Current estimate of the value of the current state.
  • α: Learning rate or step size.
  • Rt+1: Immediate reward received after the transition.
  • γ: Discount factor.
  • V(St+1): Estimated value of the successor state.

Bootstrapping

TD learning uses a concept called bootstrapping.

Instead of waiting for the final outcome, the agent updates its current estimate using another estimated value.

In the TD formula:

Rt+1 + γV(St+1)

acts as the target for updating V(St).
