Monte Carlo Methods

Model-Free Reinforcement Learning

In a real-world environment, the agent does not have access to the entire model of the environment.

For example, the agent may not know the transition matrix or the complete dynamics of the environment.

This leads to the question:

How can we compute the state values without knowing the transition matrix?

Monte Carlo methods solve this problem by using the agent's experience instead of requiring the transition model.

The value can be estimated using the equation based on the summation of rewards with the discount factor γ:

Gt = Rt+1 + γRt+2 + γ2Rt+3 + ...

This is the return obtained from a state, where future rewards are discounted using γ.

Episode

An episode is a sampling process of the environment from the beginning to the end, according to the actions taken by the agent and the rewards received.

An episode contains a sequence of states, actions, and rewards until the environment reaches a terminal state.

For example:

S0 → A0 → R1 → S1 → A1 → R2 → ... → ST

Here, T represents the time step at which the episode terminates.

Monte Carlo Policy Evaluation

Monte Carlo policy evaluation is a model-free method that estimates the state-value function for a given policy by:

  1. Collecting a large number of sample episodes.
  2. Calculating the returns obtained for the states in those episodes.
  3. Averaging the returns corresponding to each state.

The algorithm does not require the transition matrix because it learns from the actual experience generated by the environment.

We need to organize and collect enough episodes to obtain a good sample of the environment.

The algorithm often requires a large number of episodes. However, we need a sufficient number of episodes to obtain reliable estimates of the state values.

First-Visit Monte Carlo Policy Evaluation

For each episode, we compute the returns:

G0, G1, G2, ..., GT-1

for each time step of the episode, where:

t = 0, 1, 2, ..., T - 1

and T is the time step at which the episode terminates.

We then go through the states:

S0, S1, S2, ..., ST-1

and update our estimates of the state-value function for each state.

First Visit

The same state can appear more than once in the same episode.

For example:

S0 → S1 → S2 → S1 → S3

Here, S1 is visited twice.

In First-Visit Monte Carlo, the state is only considered the first time it appears in the current episode.

To update our estimate for a state St, we check whether this is the first time we have visited this state in the current episode. This is where the name First-Visit Monte Carlo comes from.

Estimating the State Value

If a state is visited for the first time in several different episodes, we collect the return obtained after each first visit.

We can then compute the average return for that state:

Vπ(s) = Average of the returns obtained after first visiting state s

Therefore, as we collect more episodes, the estimate of the state-value function is updated using more samples from the environment.
