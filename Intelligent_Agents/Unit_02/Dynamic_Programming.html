Dynamic Programming

Policy Evaluation

In dynamic programming, policy evaluation is used to estimate the value function of a given policy.

We use the Bellman equation while considering the current policy.

The algorithm takes:

  • An arbitrary policy π.
  • A discount factor γ.

The algorithm updates the estimated value of each state by taking a weighted average of:

  • The immediate reward obtained in the next time step.
  • The estimated value of the next state.

The current policy π is used to select the next action, which is captured in the Bellman equation.

Policy Evaluation Algorithm

while not converge:
delta = 0

for s ∈ S:
    V = Vπ(s)

    Vπ(s) = Bellman equation using policy π

    delta = max(delta, |V - Vπ(s)|)

if delta < tol:
    stop

The important idea is that policy evaluation only evaluates the policy. It does not improve or change the policy.

In the lab, the policy evaluation algorithm was used to calculate the value function for a given policy.

Policy Evaluation vs. Value Iteration

In value iteration, we did not evaluate a specific policy. Instead, we directly use the reward and the possible next states to calculate the optimal value.

The value iteration update considers:

  • The reward R(s,a).
  • The transition probabilities P(s'|s,a).
  • The current estimate of the optimal value V*(s').
  • The maximum over possible actions.

Therefore, the main distinction is:

  • Policy evaluation: evaluates a given policy π.
  • Value iteration: directly searches for the optimal value by considering the best action.

Policy Improvement

The ultimate goal of reinforcement learning is to find an optimal policy that maximizes the expected return for all states in the state space.

However, searching through every possible policy can be computationally expensive.

Why Brute Force Is Expensive

For example, consider a grid with:

  • 4 possible actions per state.
  • 12 states.

The number of possible deterministic policies is:

4^12 = 16,777,216

Therefore, checking every possible policy using brute force can be computationally expensive.

Instead of searching through every possible policy, we can make small iterative improvements to the current policy.

We can determine whether a modified policy is better by using the estimated state-action value Qπ.

Policy Improvement Main Idea

For two deterministic policies π and π', the policy improvement principle states:

Vπ'(s) ≥ Vπ(s)

In other words, a modified policy is better than the original policy if it increases the expected return for at least one state, while not decreasing it for the others.

Policy Improvement Phases

  1. Calculate Q

    Calculate the state-action values Qπ(s,a) for the possible actions.

  2. Select the Best Action

    Assign probability 1 to the action with the maximum Q value and probability 0 to the remaining actions.

The main idea is to improve the current policy by choosing the action with the highest estimated state-action value.

Dynamic Programming and the Environment Model

Dynamic programming methods assume that the agent has access to a perfect model of the environment.

This includes:

  • The reward function.
  • The dynamics or transition function.

Therefore, dynamic programming methods are considered model-based reinforcement learning methods.

However, in real-world reinforcement learning problems, the true model of the environment may be unknown to the agent, and the state or action spaces may be very large.

Monte Carlo Methods

Monte Carlo methods are model-free reinforcement learning methods.

Unlike dynamic programming, Monte Carlo methods do not require a model of the environment. Instead, they use the agent's experience to estimate value functions by averaging sample returns.

Monte Carlo methods use sequences of:

  • States.
  • Actions.
  • Rewards.

The agent can interact with a simulated environment to generate these samples.

Monte Carlo and the Bellman Equation

Since Monte Carlo is a model-free reinforcement learning method, we cannot use the model of the environment and the Bellman equation as the update mechanism used in dynamic programming.

The question becomes:

How can we compute state values when using Monte Carlo?

Monte Carlo methods estimate the value of a state using the returns obtained from complete episodes.

The return can be represented as:

Gt = Rt+1 + γGt+1

Here, γ is the discount factor.

The discount factor is used to reduce the contribution of rewards that occur further in the future. A smaller discount factor gives less importance to future rewards.

This equation comes from the summation of rewards while adding a discount factor γ to future rewards.

Monte Carlo Policy Evaluation

Monte Carlo policy evaluation estimates the state-value function Vπ using the returns experienced by the agent while following policy π.

The agent needs to experience many scenarios or episodes in order to obtain enough samples to estimate the state values.

The state-value function represents the expected return obtained when starting from a particular state and following the policy.

The general idea is:

  1. The agent follows a policy.
  2. The agent interacts with the environment.
  3. The agent observes states, actions, and rewards.
  4. The episode produces a return for the visited states.
  5. The returns are averaged to estimate the state value.
