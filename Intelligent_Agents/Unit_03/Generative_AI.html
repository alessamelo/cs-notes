1. Introduction to Generative Artificial Intelligence

1.1. What is Generative AI?

Generative Artificial Intelligence (Generative AI) is a branch of Artificial Intelligence that focuses on creating new content based on patterns learned from training data. Unlike traditional AI systems that primarily classify, predict, or recognize information, Generative AI models can produce new outputs that resemble the data on which they were trained. These outputs can include:
  • Text: Articles, summaries, conversations, code, and translations.
  • Images: Illustrations, photographs, digital artwork, and designs.
  • Audio: Speech, music, and sound effects.
  • Video: Generated animations and video sequences.
  • Code: Programming solutions, functions, and complete software components.
Generative AI models learn the underlying statistical patterns and relationships in their training data. They use this knowledge to generate new outputs.

1.2. Generative AI vs. Traditional AI

Traditional AI systems are frequently designed to make predictions or decisions based on input data. For example:
  • A classification model determines whether an email is spam or legitimate.
  • A regression model predicts the price of a house.
  • An image recognition model identifies objects in a photograph.
Generative AI focuses on producing new content. For example:
  • A language model generates an email based on a user instruction.
  • An image generation model creates an illustration from a text description.
  • A code generation model produces a Python function from a programming requirement.
Characteristic Traditional AI Generative AI
Main objective Prediction, classification, or decision-making Generating new content
Output Labels, predictions, or scores Text, images, audio, video, or code
Example Spam detection Email generation
Common models Decision Trees, Random Forests, SVMs Transformers, GANs, VAEs, Diffusion Models

1.3. Large Language Models (LLMs)

Large Language Models (LLMs) are generative AI models trained on large collections of textual data. Their primary objective is to learn the statistical relationships between tokens and predict the next token given a sequence of previous tokens. A token is a basic unit of text processed by a language model. It can represent:
  • A complete word.
  • A part of a word.
  • A punctuation mark.
  • A character or other text element.
For example, given the sequence:
The cat sat on the ...
The model calculates a probability distribution over possible next tokens. Possible predictions could include:
  • mat
  • floor
  • chair
  • table
The model selects a token according to its generation strategy and adds it to the existing sequence. This process is repeated autoregressively until the model reaches a stopping condition.

1.4. Autoregressive generation

Autoregressive generation means that each newly generated token depends on the previously generated tokens. Mathematically, the probability of a sequence can be expressed using the chain rule: $$P(x_1,x_2,\ldots,x_n)= \prod_{t=1}^{n}P(x_t|x_1,\ldots,x_{t-1})$$ The model predicts one token at a time:
  1. Receive the initial prompt.
  2. Process the input sequence.
  3. Calculate the probability distribution of the next token.
  4. Select a token using a decoding strategy.
  5. Append the selected token to the sequence.
  6. Repeat until generation stops.

2. Transformers: Attention Is All You Need

2.1. Introduction to Transformers

Transformers are a neural network architecture introduced in the research paper:
Attention Is All You Need
Ashish Vaswani et al., 2017.
The paper introduced an architecture based entirely on attention mechanisms, eliminating the need for recurrent and convolutional layers as the primary mechanisms for sequence modeling. Before Transformers, many sequence-processing models relied on Recurrent Neural Networks (RNNs), including Long Short-Term Memory networks (LSTMs) and Gated Recurrent Units (GRUs). These architectures processed sequences sequentially, which made parallel computation more difficult. Transformers introduced a different approach: instead of processing tokens one after another through recurrent connections, they use attention mechanisms to model relationships between tokens.

2.2. The problem with traditional sequence models

Recurrent Neural Networks process sequences in chronological order. For example, given the sentence:
The animal didn't cross the street because it was tired.
The model must understand that the word "it" refers to "the animal". RNNs process the sentence sequentially, maintaining a hidden state that carries information from previous tokens. However, traditional recurrent architectures can experience:
  • Difficulty learning long-range dependencies.
  • Vanishing and exploding gradient problems.
  • Limited parallelization during training.
  • Increasing computational dependencies as sequence length grows.
Transformers address these limitations through attention mechanisms.

2.3. The Attention Mechanism

Attention allows a model to determine which parts of an input sequence are important when processing a particular token. Instead of relying only on the immediately preceding token, the model can consider relationships between different positions in the sequence. For example:
The dog chased the ball because it was moving.
When processing the word "it", the attention mechanism can assign different importance to the previous words to identify relevant contextual information. The fundamental idea is that each token can establish relationships with other tokens in the sequence.

2.4. Scaled Dot-Product Attention

The central attention operation introduced in the paper is called Scaled Dot-Product Attention. It uses three components:
  • Query (Q): Represents what information a token is looking for.
  • Key (K): Represents the information available for comparison.
  • Value (V): Represents the information that can be retrieved.
The attention mechanism compares queries with keys to calculate attention scores. The mathematical equation is: $$Attention(Q,K,V)= softmax\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$ Where:
  • $Q$: Query matrix.
  • $K$: Key matrix.
  • $V$: Value matrix.
  • $d_k$: Dimension of the key vectors.
  • $QK^T$: Similarity scores between queries and keys.
  • $\sqrt{d_k}$: Scaling factor.
  • $softmax$: Converts attention scores into normalized weights.
The process works as follows:
  1. Calculate the similarity between queries and keys using a dot product.
  2. Divide the scores by $\sqrt{d_k}$ to prevent excessively large values.
  3. Apply Softmax to obtain normalized attention weights.
  4. Multiply the attention weights by the value vectors.
  5. Combine the weighted values to obtain the attention output.
The result is a representation in which each token incorporates information from other relevant tokens.

2.5. Why do we divide by the square root of the dimension?

The scaling factor prevents the dot-product values from becoming excessively large when the dimensionality of the key vectors increases. Large values can cause the Softmax function to produce extremely concentrated probability distributions. This can lead to very small gradients, making optimization more difficult. Dividing by $\sqrt{d_k}$ helps maintain more stable attention scores and gradients.

2.6. Multi-Head Attention

The Transformer architecture uses Multi-Head Attention. Instead of calculating attention only once, it performs multiple attention operations in parallel. Each attention head can learn to focus on different relationships between tokens. For example:
  • One head might focus on grammatical relationships.
  • Another might focus on relationships between subjects and verbs.
  • Another might capture long-distance contextual dependencies.
These are illustrative possibilities; the model does not explicitly assign a predefined linguistic function to each head. The outputs of the attention heads are concatenated and passed through a learned linear transformation. The equation is: $$MultiHead(Q,K,V)= Concat(head_1,\ldots,head_h)W^O$$ Where each attention head is calculated as: $$head_i=Attention(QW_i^Q,KW_i^K,VW_i^V)$$ The matrices $W_i^Q$, $W_i^K$, $W_i^V$, and $W^O$ are learned parameters.

2.7. Positional Encoding

Unlike RNNs, Transformers do not process tokens sequentially by default. Therefore, they need an additional mechanism to represent the order of tokens. The original Transformer architecture introduced Positional Encoding. Positional encodings are added to token embeddings to provide information about their positions in the sequence. The original paper used sinusoidal functions: $$PE(pos,2i)= \sin\left(\frac{pos}{10000^{2i/d_{model}}}\right)$$ $$PE(pos,2i+1)= \cos\left(\frac{pos}{10000^{2i/d_{model}}}\right)$$ Where:
  • $pos$: Position of the token in the sequence.
  • $i$: Dimension index.
  • $d_{model}$: Embedding dimension.
These positional encodings allow the model to incorporate information about token order.

2.8. Transformer Architecture

The original Transformer architecture consists of two main components:
  • Encoder: Processes the input sequence and creates contextual representations.
  • Decoder: Generates the output sequence using the encoder representations and previously generated tokens.
Encoder components:
  1. Multi-Head Self-Attention.
  2. Residual connection and Layer Normalization.
  3. Position-wise Feed-Forward Network.
  4. Another residual connection and Layer Normalization.
Decoder components:
  1. Masked Multi-Head Self-Attention.
  2. Residual connection and Layer Normalization.
  3. Encoder-Decoder Attention.
  4. Residual connection and Layer Normalization.
  5. Position-wise Feed-Forward Network.
  6. Another residual connection and Layer Normalization.

2.9. Masked Self-Attention

The decoder uses masked self-attention to prevent the model from accessing future tokens during autoregressive generation. For example, when predicting the third token, the model can use the first and second tokens but cannot use the fourth or subsequent tokens. This ensures that the model learns to predict the next token using only the available preceding context.

2.10. Feed-Forward Networks

Each Transformer encoder and decoder layer contains a position-wise Feed-Forward Network. It consists of two linear transformations with a non-linear activation function between them. In the original paper, the function is: $$FFN(x)=max(0,xW_1+b_1)W_2+b_2$$ This component transforms the representations produced by the attention mechanism.

2.11. From Transformers to modern LLMs

The Transformer architecture became the foundation for many modern language models. However, not all modern Transformer models use the complete original encoder-decoder architecture. There are three major architectural approaches:
  • Encoder-only: Processes input sequences and creates contextual representations. Example: BERT.
  • Decoder-only: Uses causal attention to generate sequences autoregressively. Examples: GPT-style models.
  • Encoder-decoder: Uses an encoder to process the input and a decoder to generate the output. Examples: T5 and the original Transformer.
Modern Generative AI systems commonly use decoder-only Transformers for general-purpose text generation.

Reference: Vaswani et al. (2017), Attention Is All You Need.

3. Prompt Engineering

3.1. What is Prompt Engineering?

Prompt Engineering is the process of designing and structuring instructions given to a generative AI model to obtain more relevant, accurate, and useful outputs. A prompt is the input provided to the model. It can contain:
  • Instructions.
  • Contextual information.
  • Examples.
  • Constraints.
  • Expected output format.
  • Additional information needed to complete the task.
The quality and structure of a prompt can significantly influence the generated response.

3.2. Elements of a good prompt

A well-structured prompt can include the following components:
  1. Role: Defines the perspective or expertise the model should adopt.
  2. Task: Explains what the model must accomplish.
  3. Context: Provides the relevant background information.
  4. Constraints: Defines limitations, requirements, or restrictions.
  5. Output format: Specifies how the response should be structured.
  6. Examples: Demonstrates the expected behavior or output.

3.3. Example of prompt engineering

Basic prompt:
Explain machine learning.
This prompt is relatively broad and does not specify the desired level of detail or format. Improved prompt:
Act as a university professor specializing in Artificial Intelligence. Explain the fundamental concepts of Machine Learning to a computer science student. Cover supervised learning, unsupervised learning, and reinforcement learning. Include practical examples, mathematical definitions, and a comparison table. Use technical but accessible language and organize the answer into sections.
The improved prompt provides context, specifies the task, and defines the expected output.

4. Temperature

4.1. What is Temperature?

Temperature is a parameter used during text generation to control the randomness of token selection. It modifies the probability distribution over the possible next tokens. Temperature is commonly represented by the parameter $T$. It is generally non-negative. A temperature of zero is supported by some generation systems as a greedy or nearly greedy decoding setting. Other systems may use a small positive value instead. Temperature can also be greater than 1.

4.2. How does Temperature work?

Before selecting a token, the model produces a set of scores called logits. Temperature modifies the logits before applying Softmax. The probability of selecting a token is calculated as: $$P(x_i)=\frac{e^{z_i/T}}{\sum_j e^{z_j/T}}$$ Where:
  • $z_i$: Logit associated with token $i$.
  • $T$: Temperature.
  • $P(x_i)$: Probability of selecting token $i$.
Temperature changes the shape of the probability distribution.

4.3. Low Temperature

Low temperatures make the probability distribution more concentrated around the most probable tokens. Consequently:
  • The most probable tokens become more likely.
  • Less probable tokens become less likely.
  • Generation becomes more focused and predictable.
  • The output generally contains less variation.
A very low temperature approaches greedy selection, in which the most probable token is selected at each step.

4.4. High Temperature

High temperatures make the probability distribution flatter. Consequently:
  • Less probable tokens become more likely.
  • The difference between token probabilities decreases.
  • Generation becomes more diverse and unpredictable.
  • The model has more opportunities to select alternative continuations.
High temperature does not mean that the model selects completely random tokens. The probability distribution still influences token selection.

4.5. Probability distribution example

Suppose the model predicts the next token using the following initial probabilities:
Token Original probability
mat 0.60
floor 0.25
chair 0.10
table 0.05
At low temperature, the probability of selecting "mat" becomes more dominant. At high temperature, the probabilities become more evenly distributed, increasing the chance of selecting alternatives such as "floor" or "chair".

4.6. Practical temperature recommendations

Application Suggested temperature Reason
Creative writing 0.8 Allows more diversity and creative responses.
Code generation 0.1 - 0.3 Encourages consistent and predictable outputs.
Customer service / Chatbots 0.2 - 0.4 Encourages consistency and controlled responses.
FrozenLake / deterministic planning Low, or greedy selection Reduces unnecessary variation in action selection.

These values are illustrative starting points. The best temperature depends on the model, task, and evaluation criteria.

5. Top-K Sampling

5.1. What is Top-K?

Top-K sampling is a decoding strategy that limits the number of candidate tokens considered when generating the next token. Instead of considering the entire vocabulary, the model only considers the K most probable tokens. The parameter $K$ determines the number of candidate tokens.

5.2. How does Top-K work?

Suppose the model generates the following probability distribution:
Token Probability Rank
mat 0.40 1
floor 0.25 2
chair 0.15 3
table 0.10 4
car 0.06 5
cloud 0.04 6
If $K=3$, only the following tokens are considered:
  • mat
  • floor
  • chair
The remaining tokens are excluded from the candidate set. The probabilities of the selected tokens are then renormalized so that they sum to 1.

5.3. What happens when K = 1?

If: $$K=1$$ Only the most probable token remains available. Therefore, Top-K sampling becomes equivalent to greedy selection at that step, regardless of temperature.

5.4. Advantages of Top-K

  • Reduces the number of possible candidate tokens.
  • Prevents the selection of very unlikely tokens.
  • Provides direct control over the size of the candidate set.
  • Can improve the coherence of generated text.

5.5. Limitations of Top-K

Top-K always considers a fixed number of candidate tokens. However, the probability distribution can vary significantly between generation steps. For example:
  • Sometimes the next token is highly predictable.
  • Sometimes many different tokens are plausible.
A fixed K does not adapt to these changes.

6. Top-P Sampling (Nucleus Sampling)

6.1. What is Top-P?

Top-P sampling, also called Nucleus Sampling, is a decoding strategy that dynamically determines the number of candidate tokens based on their cumulative probability. Unlike Top-K, which uses a fixed number of tokens, Top-P selects the smallest group of most probable tokens whose cumulative probability reaches or exceeds a specified threshold $p$. This group is called the nucleus.

6.2. How does Top-P work?

Consider the following probability distribution:
Token Probability Cumulative probability
mat 0.40 0.40
floor 0.25 0.65
chair 0.15 0.80
table 0.10 0.90
car 0.06 0.96
cloud 0.04 1.00
Suppose: $$TopP=0.80$$ The model selects the smallest group of tokens whose cumulative probability reaches at least 0.80. The selected nucleus is:
  • mat: 0.40
  • floor: 0.25
  • chair: 0.15
The cumulative probability is: $$0.40+0.25+0.15=0.80$$ The other tokens are excluded from the candidate set. The probabilities of the remaining tokens are renormalized before sampling.

6.3. Why is Top-P dynamic?

Top-P adapts the number of candidate tokens according to the shape of the probability distribution. For example:
  • If the model is very confident about the next token, the nucleus may contain only a few tokens.
  • If the model is uncertain, the nucleus may contain many more tokens.
Therefore, Top-P provides a flexible alternative to Top-K.

6.4. Advantages of Top-P

  • Adapts the candidate set to the probability distribution.
  • Excludes tokens with very low probabilities.
  • Allows diversity without considering the entire vocabulary.
  • Can produce more natural and contextually appropriate outputs.

7. Comparing Temperature, Top-K, and Top-P

7.1. Main differences

These three parameters influence token generation, but they perform different functions.
Parameter Function Main effect
Temperature Modifies the probability distribution. Controls randomness.
Top-K Limits the number of candidate tokens. Uses a fixed candidate count.
Top-P Limits candidates using cumulative probability. Uses a dynamic candidate count.

7.2. Example: "The cat sat on the..."

Without Top-K or Top-P restrictions, the model can theoretically sample from the entire vocabulary. This means that even very unlikely tokens could be selected, depending on their probabilities and the sampling procedure. With Top-K: The model only considers the K most probable tokens. With Top-P: The model considers the smallest set of tokens that reaches the cumulative probability threshold. With Temperature: The probabilities of the candidate tokens are modified before sampling. These parameters can be combined, although the exact order and implementation may depend on the generation system.

7.3. Practical parameter recommendations

Creative writing
  • Temperature: 0.8.
  • Top-P: Relatively high, for example 0.9.
  • Top-K: Moderate or high, depending on the system.
Objective: Increase diversity and allow the model to explore alternative expressions and ideas. Code generation
  • Temperature: 0.1 - 0.3.
  • Top-P: 0.7 - 0.9.
  • Top-K: 10 - 20.
Objective: Generate more consistent and predictable outputs while reducing unnecessary variation. Customer service and chatbots
  • Temperature: 0.2 - 0.4.
  • Top-P: 0.7 - 0.9.
  • Top-K: 20 - 50.
Objective: Maintain consistent responses and reduce unexpected variations. FrozenLake and reinforcement learning
  • Temperature: Low or greedy action selection.
  • Top-P: Usually unnecessary.
  • Top-K: Usually unnecessary.
Objective: Select actions based on the learned policy or Q-values.

Important distinction: Temperature, Top-K, and Top-P are language-model decoding parameters. They are not normally used directly in tabular Reinforcement Learning or standard DQN. In FrozenLake, action selection is generally controlled through epsilon-greedy exploration, a learned policy, or a softmax policy over Q-values.

7.4. Important considerations

  • Low temperature does not guarantee factual correctness.
  • High temperature does not necessarily improve creativity in every task.
  • Top-K and Top-P restrict candidate tokens but do not guarantee that the generated response is correct.
  • Using both Top-K and Top-P may further restrict the candidate set.
  • Some model APIs do not expose all three parameters.
  • Some APIs use different parameter ranges or defaults.

8. Final Summary

8.1. Important concepts

  • Generative AI: Artificial Intelligence that creates new content based on learned patterns.
  • LLM: A Large Language Model trained to understand and generate sequences of tokens.
  • Transformer: A neural network architecture based on attention mechanisms.
  • Attention: Allows the model to determine the importance of relationships between tokens.
  • Query: Represents the information a token is searching for.
  • Key: Represents information used to calculate attention scores.
  • Value: Represents the information retrieved through attention.
  • Positional Encoding: Provides information about token positions.
  • Prompt Engineering: Designing instructions to guide model outputs.
  • Temperature: Controls the concentration of the probability distribution.
  • Top-K: Restricts sampling to a fixed number of the most probable tokens.
  • Top-P: Restricts sampling to a dynamically selected group based on cumulative probability.

8.2. Important equations

Autoregressive probability: $$P(x_1,\ldots,x_n)=\prod_{t=1}^{n} P(x_t|x_1,\ldots,x_{t-1})$$ Scaled Dot-Product Attention: $$Attention(Q,K,V)= softmax\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$ Multi-Head Attention: $$MultiHead(Q,K,V)= Concat(head_1,\ldots,head_h)W^O$$ Temperature sampling: $$P(x_i)=\frac{e^{z_i/T}}{\sum_j e^{z_j/T}}$$
