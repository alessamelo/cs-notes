8. Deep Q-Networks (DQN)

8.1. Introduction to neural networks

Before understanding Deep Q-Networks, we need to understand the basic idea of an artificial neural network. A single artificial neuron is a simplified mathematical model inspired by biological neurons. It receives input values, multiplies them by weights, adds a bias, and applies an activation function. The mathematical expression is: $$z=\sum_{i=1}^{n}w_ix_i+b$$ $$y=f(z)$$ Where:
  • $x_i$: Input values.
  • $w_i$: Weights associated with each input.
  • $b$: Bias.
  • $f$: Activation function.
  • $y$: Output of the neuron.

8.2. Neural networks and supervised learning

In a basic supervised learning problem, a neural network receives an input $x$ and attempts to predict an output $y'$. The prediction is compared with the actual target $y$ using a loss function. The network adjusts its weights to reduce the prediction error. The general process is:
  1. Provide an input.
  2. Calculate the network prediction.
  3. Compare the prediction with the expected target.
  4. Calculate the loss.
  5. Use backpropagation to calculate gradients.
  6. Update the weights using an optimization algorithm.

8.3. Why do we need activation functions?

Activation functions introduce non-linearity into neural networks. Without non-linear activation functions, stacking multiple linear layers would still produce an overall linear transformation. This would limit the network's ability to learn complex relationships. Common activation functions include:
  • ReLU: $f(x)=\max(0,x)$.
  • Sigmoid: $f(x)=\frac{1}{1+e^{-x}}$.
  • Tanh: $f(x)=\tanh(x)$.
  • Softmax: Converts a vector of values into a probability distribution.
ReLU is commonly used in the hidden layers of DQN networks.

8.4. From Q-Learning to Deep Q-Networks

Traditional Q-Learning stores action values in a Q-table. This works well when the state space and action space are relatively small and discrete. However, when the state space becomes very large or continuous, storing every possible state-action pair becomes impractical. Deep Q-Networks solve this problem by using a neural network to approximate the Q-function. Instead of storing all Q-values in a table, the network learns a mapping: $$Q(s,a;\theta)$$ Where:
  • $s$: State provided as input.
  • $a$: Available action.
  • $\theta$: Neural network parameters.
  • $Q(s,a;\theta)$: Estimated action value.
In a standard DQN architecture, the network receives the state and produces one Q-value for each available discrete action. $$Q(s;\theta)=[Q(s,a_1),Q(s,a_2),\ldots,Q(s,a_n)]$$ The agent selects an action using an exploration strategy such as epsilon-greedy.

8.5. DQN and Q-Learning

DQN combines the Q-Learning algorithm with a deep neural network. The objective is still to approximate the optimal action-value function. The target used to train the network is based on the Q-Learning update: $$y_t=R_{t+1}+\gamma\max_{a'}Q(S_{t+1},a';\theta^-)$$ Where $\theta^-$ represents the parameters of the target network. The network is trained by minimizing the difference between its predicted Q-value and the target: $$L(\theta)=\mathbb{E}[ (y_t-Q(S_t,A_t;\theta))^2]$$

8.6. Main components of DQN

A standard DQN implementation introduces two important mechanisms: 1. Experience Replay: The agent stores previous transitions in a replay buffer. Each transition contains: $$ (S_t,A_t,R_{t+1},S_{t+1},Done) $$ During training, the agent samples random batches of transitions from this buffer. Benefits:
  • Reduces correlations between consecutive experiences.
  • Allows the agent to reuse previously collected experiences.
  • Improves training stability and data efficiency.
2. Target Network: DQN maintains a separate target network to calculate the target Q-values. The target network has parameters $\theta^-$, while the online network has parameters $\theta$. The online network is updated during training. The target network is periodically synchronized with the online network. This helps stabilize the learning process because the target values do not change after every gradient update.

8.7. DQN training process

  1. Initialize the online Q-network.
  2. Initialize the target network with the same parameters.
  3. Initialize the replay buffer.
  4. Observe the current state.
  5. Select an action using epsilon-greedy.
  6. Execute the action in the environment.
  7. Observe the reward and next state.
  8. Store the transition in the replay buffer.
  9. Sample a random mini-batch of transitions.
  10. Calculate the target Q-values using the target network.
  11. Calculate the loss between predicted and target Q-values.
  12. Update the online network using backpropagation and gradient descent.
  13. Periodically synchronize the target network.
  14. Repeat the process.

8.8. DQN characteristics

  • Model-free Reinforcement Learning.
  • Off-Policy learning.
  • Based on Q-Learning.
  • Uses a neural network to approximate the action-value function.
  • Uses experience replay.
  • Uses a target network.
  • Designed primarily for environments with discrete action spaces.

10.2. Important equations to remember

Policy: $$\pi(a|s)=P(A_t=a|S_t=s)$$ State-value function: $$V^\pi(s)=\mathbb{E}_\pi[G_t|S_t=s]$$ Action-value function: $$Q^\pi(s,a)=\mathbb{E}_\pi[G_t|S_t=s,A_t=a]$$ Bellman expectation equation: $$V^\pi(s)=\sum_a\pi(a|s)\sum_{s'}P(s'|s,a) [R(s,a,s')+\gamma V^\pi(s')]$$ Bellman optimality equation: $$V^*(s)=\max_a\sum_{s'}P(s'|s,a) [R(s,a,s')+\gamma V^*(s')]$$ Monte Carlo update: $$V(S_t)\leftarrow V(S_t)+\alpha[G_t-V(S_t)]$$ TD(0) update: $$V(S_t)\leftarrow V(S_t)+\alpha[ R_{t+1}+\gamma V(S_{t+1})-V(S_t)]$$ SARSA update: $$Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha[ R_{t+1}+\gamma Q(S_{t+1},A_{t+1})-Q(S_t,A_t)]$$ Q-Learning update: $$Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha[ R_{t+1}+\gamma\max_{a'}Q(S_{t+1},a')-Q(S_t,A_t)]$$ DQN target: $$y_t=R_{t+1}+\gamma\max_{a'}Q(S_{t+1},a';\theta^-)$$
