Historical journey

1950s — Foundations of AI

  • The idea of machines exhibiting intelligent behavior emerged in the 1950s.
  • In 1950, Alan Turing published Computing Machinery and Intelligence, introducing what later became known as the Turing Test.
  • Turing is one of the foundational figures in computer science and artificial intelligence, although calling him the founder of AI is too simplistic.
  • In 1956, the Dartmouth Summer Research Project on Artificial Intelligence took place.
    • The term "artificial intelligence" was proposed by John McCarthy.
    • The conference is generally considered the event that established AI as a distinct research field.

Early AI

Early AI focused primarily on symbolic reasoning, using:

  • Rules
  • Logical inference
  • Symbolic representations
  • Search algorithms
  • Manually encoded knowledge

These systems were not learning from massive datasets as modern AI systems do.

1960s — ELIZA and Early Natural Language Processing

In 1966, Joseph Weizenbaum developed ELIZA at MIT.

ELIZA was an early natural-language processing (NLP) program designed to simulate a conversation with a Rogerian psychotherapist.

It can be considered an important predecessor to modern chatbots, although calling it a modern "intelligent agent" would be somewhat anachronistic.

How ELIZA Worked

ELIZA did not understand language in the modern sense and did not use machine learning.

It used:

  • Keywords
  • Pattern matching
  • Decomposition rules
  • Reassembly rules
  • Substitutions
  • Manually written conversational scripts

The program repeatedly followed a basic cycle: 

User input
    ↓
Analyze/match patterns
    ↓
Identify relevant keywords
    ↓
Select a rule
    ↓
Transform/reassemble the input
    ↓
Generate response
    ↓
Wait for next input

The famous DOCTOR script contained categories and patterns related to topics such as:

  • Feelings
  • Family
  • Beliefs
  • Reasons
  • Difficulties
  • Wants and needs
  • Dreams
  • Yes/no statements
  • Deflection strategies

The important point is that ELIZA could produce apparently meaningful conversation through symbolic manipulation of language, despite having no genuine understanding or learning mechanism.

1980s — Intelligent Agents

During the 1980s, the concept of intelligent agents became increasingly prominent in AI research.

The focus began moving toward systems that could:

  • Perceive their environment
  • Maintain some internal state
  • Make decisions
  • Pursue goals
  • Act autonomously

This represented a shift from AI programs that simply solved isolated problems toward systems that could be viewed as entities interacting with an environment.

1990s — Software Agents and the Internet

During the 1990s, software agents became increasingly relevant for practical applications, helped by the rapid expansion of the Internet and World Wide Web.

Examples included:

  • Web crawlers
  • Information retrieval agents
  • Recommendation systems
  • Personal assistants
  • Automated monitoring systems

Web Crawlers

Web crawlers automatically visited webpages and followed links to discover and collect information.

They became particularly important as the amount of information available on the Web grew.

Before Google became dominant, search engines such as AltaVista, Lycos, Excite, and Yahoo! already provided Web search capabilities.

Therefore, it is more accurate to say that web crawlers enabled automated discovery and indexing of the rapidly growing Web; they did not appear only because Google did not yet exist.

2000s — Big Data and Machine Learning

During the 2000s, AI increasingly benefited from:

  • Larger datasets
  • Increased storage capacity
  • Faster processors
  • Improved algorithms
  • The expansion of the Internet
  • Improved machine-learning techniques

The growth of digital data provided substantially more information from which machine-learning systems could learn.

This contributed to a gradual transition from primarily hand-crafted rules toward data-driven approaches.

Rule-Based AI vs. Machine Learning

Earlier AI:
Human → defines rules → Computer applies rules

Machine Learning:
Human → provides data → Algorithm learns patterns

2010s — Deep Learning Revolution

The 2010s saw a major expansion of deep learning, driven by the combination of:

  • Large datasets
  • GPUs
  • Improved neural-network architectures
  • Distributed computing
  • Advances in optimization

Deep learning significantly improved areas such as:

  • Computer vision
  • Speech recognition
  • Natural language processing
  • Recommendation systems

This period saw the emergence of widely used AI assistants such as:

  • Apple Siri
  • Google Now
  • Amazon Alexa

These systems used combinations of technologies including automatic speech recognition, natural language processing, machine learning, and deep neural networks.

Why Deep Learning Became Important

Traditional algorithms often relied heavily on manually engineered features. Deep learning could instead learn increasingly complex representations directly from large amounts of data. 

Traditional approach:

Raw data
   ↓
Human-designed features
   ↓
Machine-learning algorithm
   ↓
Prediction


Deep learning:

Raw data
   ↓
Neural network
   ↓
Learned representations
   ↓
Prediction

2020s — Large Language Models

The 2020s brought the rapid development and deployment of large language models (LLMs).

Important examples include:

  • GPT-3
  • GPT-4
  • Google Bard/Gemini
  • Microsoft Copilot

LLMs are based primarily on the Transformer architecture and are trained on very large collections of data.

Modern AI systems can be constructed on top of LLMs, using them as a foundation for applications such as:

  • Chatbots
  • Coding assistants
  • Intelligent agents
  • Information retrieval systems
  • Autonomous task systems
  • Multimodal applications

Today — Modern AI and Intelligent Agents

Modern AI combines several important technologies:

Big Data

Large datasets provide the information required to train increasingly capable models.

Deep Learning

Neural networks learn complex representations from data.

Transformers

Transformer architectures allow models to process relationships between elements of sequences efficiently and have become fundamental to modern NLP and LLMs.

Self-Supervised Learning

Models learn from large quantities of largely unlabeled data by constructing training objectives from the data itself.

Fine-Tuning

A pretrained model can be adapted to a particular task, domain, or behavior using additional training.

Retrieval-Augmented Generation (RAG)

Models can retrieve external information and use it as context when generating responses.

AI Agents

Modern agents can combine an LLM with:

  • Memory and state
  • Tools
  • External APIs
  • Planning
  • Environment interaction
  • Feedback
  • Task-specific objectives

Key Conceptual Distinction

The history should not be presented simply as ELIZA → intelligent agents → LLMs, as if these were successive versions of the same technology.

They are better understood as different approaches that progressively contributed concepts and techniques to AI.

ELIZA is particularly useful because it demonstrates an important distinction:

A system can produce apparently intelligent language behavior without actually understanding language.

This distinction remains relevant when discussing whether modern AI systems truly understand language or instead learn highly sophisticated statistical representations and patterns.
