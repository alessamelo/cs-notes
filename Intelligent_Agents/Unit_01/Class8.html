Markov Decision Process - Part 3

MDP

An MDP extends the MRP by including actions and a policy into the process.

Policy

In Reinforcement Learning, the agent has the ability to decide how to act in the environment. However, it is not always clear how the agent chooses an action given a state or what rules it uses to make the decision. The policy describes this decision process.

Policy π

A policy is a function that maps each state s to a probability distribution over the set of all possible actions in that state.

A policy can be:

  • Deterministic: it always chooses the same action given a particular state.
  • Stochastic: it chooses actions according to a probability distribution.

π(a|s) = P[At = a | St = s]

for all s ∈ S and a ∈ A.

The probabilities of all possible actions in a given state must sum to 1:

∑a π(a|s) = 1

Formally, we say that an agent follows a policy.

Objective of Reinforcement Learning

In Reinforcement Learning, the objective is to formulate effective policies that specify which action to take in each state in order to maximize the return.

Two important questions are:

  • How probable is it that an agent selects an action given its state? This is described by the policy.
  • How good was the action? This is described by the value function.

Value Functions

The goal of Reinforcement Learning is to maximize the reward. For this, we use value functions.

A value function measures the expected return when following a particular policy.

There are two different value functions:

  • State-value function: V
  • State-action value function: Q

State-Value Function V

The state-value function measures the expected return starting in a state and then following a policy up to a horizon H, where H is the length of an episode.

It gives us the value of a state under a policy π.

Return

Gt = Rt + λRt+1 + λ2Rt+2

State-Value Equation

Vπ(s) = Eπ[Gt | St = s]

Therefore, Vπ(s) represents the expected return when starting from state s and following policy π.

State-Action Value Function Q

The state-action value function evaluates the expected return when starting in a state and taking a particular action.

Qπ(s,a) = Eπ[Gt | St = s, At = a]

Therefore, Qπ(s,a) tells us the expected return when the agent is in state s, takes action a, and then follows policy π.

GPS Analogy

A GPS can be used as an analogy for understanding policies and value functions.

  • Policy: turn-by-turn directions, such as "turn left at the next light."
  • Value function: the estimated time of arrival (ETA), which tells us how good the current route is.

A shorter ETA corresponds to a higher-value state in this analogy.
