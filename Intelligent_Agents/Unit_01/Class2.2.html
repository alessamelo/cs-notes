15. Types of Reinforcement Learning Tasks

Reinforcement learning environments can be classified according to whether the task has a defined ending and whether the outcomes of actions are predictable or uncertain.

Episodic Tasks

An episodic task is a task in which an agent interacts with an environment until it reaches a terminal state. Each episode has a clear beginning and end.

Once the terminal state is reached, the episode finishes and a new episode can begin.

Examples

  • Videogames with a defined end.
  • Board games.
  • Maze-solving tasks.
  • Spider Solitaire games, where individual games are independent episodes.

The important characteristic is that there is a terminal state. 

Episode

Start
  ↓
State → Action → State → Action → State
                                      ↓
                              Terminal State
                                      ↓
                                  Episode ends

Continuing Tasks

A continuing task does not have a terminal state. The agent continues interacting with the environment indefinitely or for as long as the system operates.

There is therefore no predefined final state that terminates the task.

Examples

  • Managing a continuous industrial process.
  • Traffic control.
  • Energy management.
  • Some robotic control systems.
State → Action → State → Action → State → Action → ...
                 ↑                              │
                 └──────────────────────────────┘
                       No terminal state

16. Deterministic vs. Stochastic Tasks

Deterministic Environment

An environment is deterministic when the result of an action is completely determined by the current state and the selected action.

In other words, if the agent knows the current state and the action it performs, the resulting next state is predictable. 

Current State + Action
          ↓
     Transition
          ↓
    Known Next State

Mathematically, a deterministic transition function can be written as: 

s' = T(s, a)

Where:

  • s = current state
  • a = selected action
  • s' = resulting next state
  • T = transition function

Example: Grid World

Consider a simple grid in which an agent must reach the goal. The environment has no randomness: moving right always moves the agent to the cell immediately to the right. 

┌───┬───┬───┬───┬───┐
│   │   │   │   │ G │
├───┼───┼───┼───┼───┤
│   │   │   │   │   │
├───┼───┼───┼───┼───┤
│ S │   │   │   │   │
└───┴───┴───┴───┴───┘

S = Start
G = Goal

Example:

State (3,1) + Action RIGHT
            ↓
        State (3,2)

If the agent is in the same state and performs the same action again, the result will always be the same.

Characteristics

  • No randomness in the transition.
  • The next state can be predicted exactly.
  • Rewards can also be fixed.
  • A transition function can describe the environment.
  • Learning can generally be easier because outcomes are predictable.

Stochastic Environment

An environment is stochastic when the same state and action can lead to different possible outcomes.

Instead of knowing exactly which state will occur, the agent can determine the probability of each possible outcome. 

Current State + Action
          ↓
   Probability Distribution
       /       |       \
      /        |        \
     ↓         ↓         ↓
 State A    State B    State C
  0.60        0.30       0.10

The transition is therefore represented using probabilities: 

P(s' | s, a)

This represents the probability of reaching state s' given the current state s and action a.

Example

Suppose an agent chooses to move right in a grid. Because of uncertainty, the action could have the following outcomes:

  • Move right → 70% probability
  • Stay in the same position → 20% probability
  • Move up → 10% probability

The agent cannot know exactly which outcome will occur. It must learn how the probabilities affect its decisions.

Characteristics

  • There is randomness or uncertainty.
  • The same action can produce different outcomes.
  • Transitions can be represented using probability distributions.
  • The agent may need to update its estimates from experience.
  • Learning can be more difficult or slower because outcomes are uncertain.

Deterministic vs. Stochastic

Characteristic Deterministic Stochastic
Outcome Predictable Uncertain
Randomness No Yes
Transition s' = T(s, a) P(s' | s, a)
Same state + action Same result Potentially different results
Learning Generally simpler Generally more difficult due to uncertainty

Important: Deterministic Problems Can Be Modeled as Stochastic

A problem that is naturally deterministic can still be represented using a stochastic model.

For example, if moving right always produces the same result, its probability can simply be represented as: 

P(Right | State, Action) = 1.0

This means that the transition occurs with 100% probability. Therefore, a deterministic environment can be considered a special case of a stochastic model in which one outcome has probability 1.

17. Model-Free vs. Model-Based Reinforcement Learning

Model-Free RL

In model-free reinforcement learning, the agent does not have a complete model of the environment.

The agent learns primarily from direct interaction, observing states, performing actions, and receiving rewards. 

State
  ↓
Action
  ↓
Environment
  ↓
Reward + New State
  ↓
Learning

The agent does not need to explicitly model all of the environment's dynamics before learning.

Example

An Atari Breakout agent can learn which paddle movements tend to produce higher rewards without explicitly constructing a complete mathematical model of the ball's physics.

Model-Based RL

In model-based reinforcement learning, the agent has or learns a model that describes the environment.

The model can describe:

  • How the environment transitions between states.
  • What rewards are obtained from actions.
  • How the environment changes over time.

The agent can use this model to predict possible future states and evaluate potential actions before executing them. 

Current State
      +
    Action
      ↓
 Environment Model
      ↓
Predicted Next State
      +
Predicted Reward
      ↓
Select Action

Model-Free vs. Model-Based

Characteristic Model-Free RL Model-Based RL
Environment model Not explicitly available Available or learned
Learning Primarily from experience and rewards Can learn from experience and predictions
Prediction Does not explicitly predict environment dynamics Predicts possible future states and rewards
Planning Limited or indirect Can use the model for planning
Example Learning paddle movements from rewards Predicting the ball trajectory before moving the paddle
