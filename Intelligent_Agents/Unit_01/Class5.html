Bellman Equations and Optimality

Bellman Expectation Equations for Vπ and Qπ

State Value Function Vπ

The Bellman Expectation Equation for the state value function is:

Vπ(s) = ∑a π(a|s) [R(s,a) + γ ∑s' P(s'|s,a)Vπ(s')]

The equation expands the Bellman expectation for Vπ by weighting the probability of taking action a when in state s under the policy π.

What the agent chooses to do is controlled by the policy π.

Optimal Policy and Optimal Value Functions

Solving an MDP means finding a new policy that earns the highest return from every state.

Given a state, there can be several actions that the agent can take. The Q function tells us that, given a state and an action, what the value is.

We want to find the action that maximizes the value.

The Goal of Reinforcement Learning

  1. Find a policy.
  2. Obtain the highest return from every state.
  3. Solve the MDP.

The idea is to find the maximum value during the trajectory. We want to have the policy that maximizes the return.

Optimality

Optimality is the policy or policies with the maximum state value over all other policies for all states in the state space.

π*(s) = arg maxπ Vπ(s)

We want to maintain only the policy that maximizes the value.

The Two Optimal Value Functions

Optimal State Value Function

V*(s) = maxπ Vπ(s)

V*(s) represents the maximum value obtainable from state s.

Optimal Action Value Function

Q*(s,a) = maxπ Qπ(s,a)

When we are in state s, suppose we have three actions that we can take. We calculate the Q function for each action. Each Q value will have its own value, and we take the maximum.

The maximum Q value determines the action the agent will make.

Bellman Optimality

The Bellman optimality equation for the state value function is:

V*(s) = maxa [R(s,a) + γ ∑s' P(s'|s,a)V*(s')]

The equation selects the action that produces the maximum expected value.

Optimal Q Function

Q*(s,a) = R(s,a) + γ ∑s' P(s'|s,a) maxa' Q*(s',a')

In GridWorld, this can be used to determine the best action from each state.

Deterministic Optimal State Value Bellman Equation

In reinforcement learning, the goal is to help the agent make decisions that lead to the best possible long-term outcomes.

State Value Equation

V(s) = maxa [R(s,a) + γV(s')]

The deterministic equation is smaller because the next state is deterministic.

The state value equation combines the reward obtained now and the expected reward in the future.

The goal of using the state value equation is to guide the agent toward an optimal policy.

How the Deterministic Bellman Equation Works

Given an initial state, we have:

  • State: s
  • Action: a
  • Reward: R(s,a)
  • Next state: s'

The agent evaluates the available actions and chooses the action that provides the highest value.

GridWorld Example

In GridWorld, the state s can be represented by a coordinate:

s = (x,y)

The possible actions are:

  • Up
  • Down
  • Left
  • Right

The next state s' is the next deterministic state resulting from the selected action.

Discount Factor γ

γ plays a control role and determines the importance of future rewards.

γ = 0

If γ is 0, the agent becomes short-sighted and only considers immediate rewards.

γ close to 1

If γ is close to 1, the agent becomes more far-sighted, taking long-term outcomes into account.

The selection of γ has to consider the environment, because sometimes short-term rewards are more important while in other situations long-term rewards are more important.

  • γ close to 0: short-sighted behavior, focusing on immediate rewards.
  • γ close to 1: far-sighted behavior, taking long-term outcomes into account.

For example, in a social network environment, using a very small γ would focus the agent on immediate rewards without sufficiently considering long-term outcomes.

The objective can therefore be to combine immediate rewards with long-term rewards.

Future rewards can be uncertain or less urgent compared with rewards that can be obtained immediately.

Value Iteration

At the beginning, the agent does not have knowledge of the environment and will move randomly.

At a certain point, the agent reaches a state next to a state that has a known value, such as a green state in GridWorld.

The agent can use this information to update the value of the neighboring state.

This process is called value iteration because we obtain a value and then update it.

Basic Process

  1. Start with initial state values.
  2. Evaluate the possible actions.
  3. Apply the Bellman optimality equation.
  4. Update the state values.
  5. Repeat the process.
