1. Recap of Previous Class

What is an Agent?

An agent is a software entity that performs tasks autonomously and on behalf of users.

What Tasks Can Intelligent Agents Struggle With?

  • Complex decision-making: Some situations involve many possible actions, changing conditions, obstacles, and ethical considerations. For example, self-driving cars must make decisions while dealing with many obstacles and unpredictable situations.
  • Large-scale autonomous systems: An example is a network of drones that could coordinate deliveries for companies such as Amazon.
  • Understanding human emotions: Agents can communicate with humans, but they do not genuinely understand human emotions. Human users may nevertheless establish emotional communication with agents, which can be problematic if the limitations of the system are ignored.
  • Ethical decision-making: Some agents can be trained using ethical considerations, but engineers cannot guarantee that an AI system will correctly handle every ethical situation.

Today's Agenda: Reinforcement Learning Principles

Reinforcement Learning (RL) studies how an agent can learn to make decisions by interacting with an environment.

Basic interaction:

Agent → Action → Environment
  ↑                  │
  │                  ↓
  └── State ← Reward

The agent performs actions in an environment. The environment responds by providing information about the resulting state and a reward.

The reward can be positive or negative. Through this interaction, the agent learns which actions are more useful for achieving its objective.

To construct a reinforcement learning system, we need to model the:

  • Environment
  • States
  • Actions
  • Rewards

3. Agent–Environment Relationship

In reinforcement learning, the agent interacts continuously with its environment. 

             Action
    Agent ───────────────→ Environment
      ↑                       │
      │                       │
      │                       ↓
      └──── State + Reward ───┘

The agent learns mainly through trial and error. When it makes a good decision, it receives a positive reward. When it makes a bad decision, it may receive a negative reward or penalty.

The general goal is to: maximize the cumulative positive reward.

Reinforcement learning is inspired in part by the way humans and animals learn from consequences.

4. Psychological Foundations of Reinforcement Learning

Reinforcement learning has connections with psychological theories of learning.

Classical Conditioning

A neutral stimulus becomes associated with a natural response.

Operant Conditioning

A behavior becomes more or less likely depending on reinforcement or punishment.

Observational Learning

Learning occurs through observing the behavior of others and its consequences.

5. Environment

The environment is the world in which the agent operates.

It can be:

  • Physical: For example, a robot navigating through a maze.
  • Virtual: For example, a videogame or computer simulation.

What Does the Environment Provide?

The environment provides two important pieces of information:

  1. State
  2. Reward

State

The state describes the relevant information about the environment that the agent needs to make a decision.

For example, in a maze, the state could include the agent's current position, nearby obstacles, and the location of the goal.

Reward

The reward is a scalar value that indicates how well the agent is performing its task.

A reward can be:

  • Positive → desirable outcome
  • Negative → undesirable outcome or penalty
  • Zero → no significant reward

Environment Dynamics

The environment has its own rules, which determine how it changes when the agent performs an action. These are called the dynamics of the environment.

In many cases, the agent does not have direct access to the underlying dynamics and must discover them through trial and error.

Different Types of Environments

  • Known environments: The rules and dynamics are explicitly defined or known. For example, many videogames have clearly defined rules.
  • Unknown or changing environments: The agent may not know the complete rules and must learn from interaction. Autonomous driving is an example because traffic, pedestrians, weather, and road conditions can continuously change.

6. What Makes an Agent Rational?

A rational agent chooses actions that are expected to maximize its performance according to the information available to it.

Performance Measure

The agent needs a criterion for determining how successful its behavior is. This criterion is called the performance measure.

The performance measure defines what the agent is trying to maximize or achieve.

Knowledge of the Environment

The agent also needs information about:

  • What actions it can perform.
  • What states it can encounter.
  • What consequences its actions may produce.
  • What sequences of actions may lead to better results.

Rationality

A rational agent attempts to choose a strategy that maximizes its expected performance in a particular environment.

8. Reflex Agent

There are many types of agents. One important type is the reflex agent.

A reflex agent selects actions based only on the current percept, ignoring the history of previous percepts.

Therefore, its decision depends on the information currently available to it.

Simple Reflex Agent

    rule ← RULE-MATCH(state, rules)

    action ← rule.action

    return action

9. Policy

In reinforcement learning, a policy defines how an agent chooses actions based on the state or observation of the environment.

As the agent learns, its policy can improve so that it chooses actions that maximize its expected cumulative reward.

In simple terms: 

State → Policy → Action

The policy guides the agent's interaction with the environment.

10. Model

A model is a mathematical description of the environment's dynamics and reward function.

Dynamic Function

The dynamic function describes how the environment evolves from one state to another after an action is performed. 

Current State + Action → Next State

Reward Function

The reward function specifies the reward that the agent receives for taking a particular action in a particular state. 

State + Action → Reward

Therefore, the model provides a mathematical representation of how the environment behaves.

11. When Should We Use Reinforcement Learning?

Reinforcement learning is particularly appropriate when the problem involves sequential decision-making.

Sequential Decision-Making

The decisions made at one point influence future states, observations, and possible decisions.

Learning Through Rewards and Penalties

RL does not require direct supervision for every action. Instead, the agent learns from rewards and penalties produced by the environment.

Example: Videogames

A videogame is a good example because:

  • The agent performs a sequence of actions.
  • Actions influence future states.
  • The agent receives points or rewards.
  • The agent can lose lives or receive penalties.
  • The agent attempts to maximize its final score.

When RL Is Not Appropriate

Reinforcement learning is generally not the natural choice for tasks such as simple object recognition when there is no sequential decision-making or interaction with an environment.

For example, classifying whether an image contains a cat or a dog is normally better treated as a supervised learning problem.
