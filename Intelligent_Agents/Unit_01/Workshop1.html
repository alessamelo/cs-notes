In this workshop, we apply the reinforcement learning concepts studied in class to the Atari game Breakout. The objective is to understand how each abstract RL concept corresponds to a concrete component of the game.

The Breakout Environment

Reinforcement Learning (RL) is a branch of machine learning in which an agent learns to make decisions by performing actions in an environment in order to maximize cumulative reward.

In Atari Breakout, the agent controls the paddle and learns how to move it in order to hit the ball, break bricks, and obtain as many points as possible.

Mapping RL Concepts to Breakout

Concept Definition Breakout Application
Agent The learner or decision-maker that interacts with the environment. The paddle or, more precisely, the software controller that decides how the paddle should move.
Environment The world in which the agent operates and that responds to the agent's actions. The Breakout game, including the game screen, ball physics, walls, paddle, and bricks.
State A representation of the environment at a particular point in time. Information such as the position and movement of the ball, the position of the paddle, and the remaining bricks.
Action One of the possible decisions or movements that the agent can perform. The paddle can move left, right, or remain neutral (No-Op).
Reward A numerical feedback signal indicating how desirable the result of an action is. The agent receives points for breaking bricks. Other actions may produce a reward of 0, while losing the ball can produce a negative consequence depending on the reward design.
Policy The strategy used by the agent to select an action based on the current state. A strategy for maximizing the number of points. For example, the agent may learn to position the paddle so that the ball can bounce toward the upper part of the screen and break more bricks.
Model A mathematical representation of how the environment behaves, including its dynamics and rewards. A mathematical model of the game's physics that can predict how the ball will move or where it will land after bouncing.

Example of the RL Cycle

  1. The agent observes the current state of the game.
  2. The agent determines the position and trajectory of the ball and the position of the paddle.
  3. The policy selects an action: left, right, or stay.
  4. The paddle moves according to the selected action.
  5. The environment changes because the ball continues moving and interacting with the paddle, walls, and bricks.
  6. The environment provides a new state and a reward.
  7. The agent uses this experience to improve its future decisions.

Policy Example

A simple policy could be expressed as: 

IF ball is to the left of the paddle
    → Move Left

IF ball is to the right of the paddle
    → Move Right

IF ball is aligned with the paddle
    → Stay

However, an RL agent does not necessarily receive this strategy explicitly. It can learn an effective policy through repeated interaction with the game.

Model-Free vs. Model-Based Reinforcement Learning

Model-Free Reinforcement Learning

In model-free RL, the agent learns through interaction and trial and error without explicitly learning a mathematical model of the environment's physics.

The agent learns which actions tend to produce better rewards without necessarily predicting the exact future state. 

State → Action → Reward
       ↓
    Learning

Model-Based Reinforcement Learning

In model-based RL, the agent learns or uses a model of the environment to predict what may happen after taking an action.

In Breakout, the agent could attempt to predict the trajectory of the ball and determine where it will reach the paddle. 

Current State
      +
    Action
      ↓
Environment Model
      ↓
Predicted Next State
      ↓
Choose Better Action

Key Difference

Model-Free Model-Based
Learns primarily from experience and rewards. Uses a model to predict future states.
Does not explicitly need to understand the game's physics. Attempts to represent or predict the game's dynamics.
Trial-and-error focused. Prediction and planning can be used.

Concept Check

Imagine that you are training an RL agent to play Breakout. The agent receives:

  • +10 for breaking a top-row brick.
  • -100 for allowing the ball to fall past the paddle.

How will this reward structure affect the way the agent learns?

Expected Reasoning

The large negative reward for losing the ball makes avoiding failure extremely important. The agent will therefore tend to learn actions that increase the probability of keeping the ball in play.

At the same time, the positive reward for breaking top-row bricks encourages the agent to discover strategies that allow it to reach those bricks.

Because the penalty of -100 is much larger than the reward of +10, the agent may prioritize survival and keeping the ball in play over immediately maximizing the number of bricks broken.

This demonstrates an important principle of reinforcement learning: the reward function strongly influences the behavior that the agent learns.
