1. Text Normalization

Text normalization is the process of transforming text into a consistent and standardized format before further processing in an NLP system.

The main goals are to:

  • Reduce noise in the data
  • Reduce unnecessary variation
  • Make text easier to process
  • Preserve meaningful information
Raw Text → Normalization → Processed Text → NLP Model

Normalization is not simply about removing as much information as possible. The appropriate preprocessing depends on the NLP task.

2. Lowercasing

Lowercasing converts all characters in the text to lowercase.

Example:

Hello World → hello world

Why use it?

It reduces the number of different representations of the same word.

Computer, computer, COMPUTER

Without lowercasing, a simple model may treat these as different tokens.

Potential Problem

Capitalization can sometimes carry useful information.

I am happy
I AM HAPPY

The second sentence may communicate stronger emotional emphasis.

Important: Lowercasing should be applied according to the NLP task. It is not always appropriate to remove capitalization.

3. Removing Punctuation

Punctuation removal eliminates characters such as:

  • Quotation marks
  • Commas
  • Periods
  • Special symbols
  • Other punctuation marks
Example:

Hello, world! → Hello world

Why remove punctuation?

  • Reduce noise
  • Simplify the vocabulary
  • Reduce the number of tokens

Potential Problem

Punctuation can contain meaningful information depending on the task.

For example, sentiment analysis may benefit from recognizing punctuation such as:

This is great!
This is great!!!

The number of exclamation marks can communicate emphasis or emotion.

4. Stemming

Stemming reduces words to a root-like form by removing prefixes or suffixes according to simple linguistic rules.
Examples:

running → run
studies → studi

Stemming generally does not consider the complete grammatical context or the part of speech of the word.

Advantage

It can reduce different word forms to a common representation, reducing vocabulary size.

Disadvantage

The resulting form may not be a valid English word.

Example: studies → studi

studi is not a normal English word.

5. Lemmatization

Lemmatization reduces a word to its base dictionary form, called its lemma, while considering linguistic information such as part of speech and context.
Examples:

running → run
studies → study
better → good

Unlike simple stemming, lemmatization attempts to produce a valid dictionary word.

Applications

  • Text classification
  • Sentiment analysis
  • Information retrieval
  • Search systems

Stemming vs. Lemmatization

Stemming Lemmatization
Usually uses simpler rules. Uses linguistic information.
May produce incomplete words. Attempts to produce valid dictionary words.
Usually faster. Usually more computationally expensive.
studies → studi studies → study

6. Stopwords

Stopwords are very common words that are often considered to contribute relatively little information for certain NLP tasks.

Examples include:

  • the
  • is
  • and
  • of

Why Remove Stopwords?

  • Improve processing efficiency
  • Reduce vocabulary size
  • Reduce dimensionality
  • Focus on potentially more informative terms

Important Limitation

Stopwords are not universally useless. Removing them can change the meaning of a sentence.

I do not like this movie.

Removing not could completely change the sentiment.

Stopword removal should therefore depend on the specific NLP task.

7. Text Tokenization

Tokenization is the process of splitting text into smaller units called tokens.

Tokens can represent words, sentences, or other units depending on the tokenizer.

Word Tokenization

Splits a text into individual words or word-like units.

"Machine learning is useful."

→ ["Machine", "learning", "is", "useful", "."]

Sentence Tokenization

Splits a document into individual sentences.

"NLP is interesting. It is widely used."

→ ["NLP is interesting.", "It is widely used."]

8. Tokenization with NLTK

NLTK (Natural Language Toolkit) is a Python library containing tools for natural language processing.

Two useful functions for tokenization are:

  • word_tokenize()
  • sent_tokenize()
from nltk.tokenize import word_tokenize, sent_tokenize

text = "NLP is interesting. It is widely used."

sentences = sent_tokenize(text)
words = word_tokenize(text)

print(sentences)
print(words)

Tokenization is commonly performed before other preprocessing and text representation techniques.

9. Text Vectorization

Text vectorization transforms textual information into numerical representations that machine learning algorithms can process.

Machine learning models generally operate on numerical data rather than raw text.

Text → Tokens → Numerical Representation → ML Model

The choice of representation affects what information the model can use.

10. Bag of Words (BoW)

Bag of Words represents text according to the occurrence or frequency of words in a document.

The basic idea is to construct a vocabulary and represent each document using the number of occurrences of each vocabulary word.

Important Characteristic

BoW ignores word order.

"dog bites man" and "man bites dog" can receive the same basic Bag-of-Words representation.

Advantages

  • Simple
  • Easy to implement
  • Useful for basic classification tasks

Limitation

Because word order is ignored, important relationships between words can be lost.

11. TF-IDF

TF-IDF (Term Frequency–Inverse Document Frequency) measures how important a word is to a document relative to a collection of documents, called a corpus.

Term Frequency — TF

Measures how frequently a term occurs in a particular document.

Inverse Document Frequency — IDF

Reduces the importance of terms that appear in many documents and increases the relative importance of terms that are more specific.

TF-IDF = TF × IDF

Main Idea

A word that appears frequently in one document but rarely across the entire corpus can be considered particularly informative for that document.

BoW: focuses mainly on word frequency.

TF-IDF: considers both word frequency and how common the word is across the corpus.

12. Encoding

Encoding transforms tokens or text representations into numerical values that can be processed by computational models.

One-Hot Encoding

Represents each token using a binary vector where one position identifies the token.

Word Embeddings

Represent words using dense numerical vectors that can capture relationships between words.

Contextual Embeddings

Represent words according to their context. Modern transformer-based models use contextual representations to capture how the meaning of a word changes depending on the surrounding text.

Technique Main Idea
One-hot encoding Binary representation identifying a token.
Word embeddings Dense numerical representation of words.
Contextual embeddings Representation depends on the surrounding context.

13. Typical NLP Preprocessing Pipeline

A simplified NLP preprocessing workflow can combine several of the techniques discussed in this class.

Raw Text → Tokenization → Normalization → Stopword Filtering → Vectorization / Encoding → ML Model

The exact pipeline is task-dependent. Not every NLP application should apply every preprocessing technique.

Key principle: preprocessing should preserve information that is useful for the task. Removing information is not automatically an improvement.

14. Normalization Techniques — Quick Review

Technique Purpose Potential Problem
Lowercasing Standardize capitalization. Can remove information expressed through capitalization.
Punctuation removal Reduce noise. Punctuation can contain emotional or structural information.
Stemming Reduce related words to a common root. Can produce incomplete or invalid words.
Lemmatization Convert words to dictionary forms. More computationally expensive than simple stemming.
Stopword removal Reduce vocabulary and dimensionality. Some stopwords are important for meaning.

15. Key Concepts to Remember

  • Normalization makes text more consistent and reduces unnecessary variation.
  • Lowercasing reduces differences caused by capitalization, but may remove useful information.
  • Stemming uses simpler rules and may produce non-words.
  • Lemmatization uses linguistic information to obtain a valid base form.
  • Stopwords can reduce vocabulary size, but should not always be removed.
  • Tokenization divides text into smaller units called tokens.
  • Vectorization converts text into numerical representations that ML models can process.
  • Bag of Words represents word frequencies but ignores word order.
  • TF-IDF measures how informative a word is within a document relative to a corpus.
  • Embeddings represent text as numerical vectors and can capture relationships between words.
