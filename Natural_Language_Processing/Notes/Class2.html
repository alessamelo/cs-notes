1. Text Normalization

Text normalization is the process of transforming text into a consistent format in order to standardize it for further processing.

The main purpose of normalization is to make text more consistent before it is processed by an NLP system.

2. Normalization Techniques

Lowercasing

Converts text into lowercase characters.

Hello World → hello world
Important: Lowercasing can sometimes remove meaning. Certain phrases can have stronger emotional meaning when people use capital letters.
I am happy
I AM HAPPY

The capitalization in the second example can communicate emphasis or stronger emotion.

Removing Punctuation

Elimination of punctuation such as quotation marks and other unnecessary symbols.

"Hello, world!" → Hello world

Stemming

Stemming reduces words to their root or stem forms by removing parts of the word.
running → run
studies → studi

Stemming can produce truncated forms that are not valid words.

Lemmatization

Lemmatization converts words to their dictionary form, called the lemma.

It considers linguistic information such as the part of speech and context.

3. Text Lemmatization

Lemmatization is the process of reducing a word to its base or dictionary form, called a lemma, while considering linguistic information such as its part of speech.

Lemmatization vs. Stemming

Lemmatization returns a valid dictionary word, while stemming often produces a truncated form of the word.

Stemming Lemmatization
Reduces a word using simpler rules. Uses linguistic information.
Can produce truncated forms. Attempts to return a valid dictionary word.
studies → studi studies → study

Applications

Lemmatization is important for applications where it is beneficial to normalize words without losing meaningful context.

  • Text classification
  • Sentiment analysis
  • Information retrieval

4. Stopwords

Stopwords are commonly occurring words that usually carry little significant information for certain text analysis tasks.

Examples include:

  • the
  • is
  • and
  • of

These words are often filtered out during text analysis.

Application

  • Improve processing efficiency
  • Reduce the number of words that must be processed
  • Focus on potentially more meaningful terms
Stopwords are not always meaningless. Whether they should be removed depends on the NLP task.

5. Text Vectorization

Text vectorization transforms text into numerical representations that can be used by machine learning algorithms.

Machine learning algorithms work with numerical data, so text must be transformed into a numerical representation before it can be processed by many traditional ML algorithms.

Text → Numerical Representation → Machine Learning Algorithm

Vectorization Techniques

Bag of Words

Bag of Words (BoW) represents text as a collection of word frequencies.

Main idea: Count how frequently each word occurs in the text.

A basic Bag-of-Words representation does not preserve word order.

TF-IDF

TF-IDF stands for Term Frequency–Inverse Document Frequency.

It measures how important a word is within a document relative to the entire collection of documents, or corpus.

TF-IDF = Term Frequency × Inverse Document Frequency

Encoding

Encoding transforms tokens into numerical values that can be processed by computational models.

Examples include:

  • One-hot encoding
  • Word embeddings
  • Contextual embeddings

6. Text Tokenization

Tokenization is the process of dividing text into smaller units called tokens.

Tokens can represent words, sentences, or other units depending on the tokenization method.

NLTK

In this course, we will use NLTK (Natural Language Toolkit) for text tokenization.

The tokenization functions can be imported from nltk.tokenize: 

from nltk.tokenize import word_tokenize, sent_tokenize

Word Tokenization

word_tokenize() divides text into individual words or word-level tokens.

"Natural language processing"

→

["Natural", "language", "processing"]

Sentence Tokenization

sent_tokenize() divides a text into individual sentences.

"NLP is useful. NLP is widely used."

→

["NLP is useful.", "NLP is widely used."]

7. NLP Preprocessing Overview

Raw Text → Tokenization → Normalization → Stopword Filtering → Vectorization → Machine Learning Model

These techniques are commonly used to prepare text for NLP applications. However, not every task requires every preprocessing step.

Key idea: NLP preprocessing should be chosen according to the task. Removing information is not always beneficial because some information may be important for understanding the text.

8. Key Concepts to Remember

  • Text normalization standardizes text for further processing.
  • Lowercasing makes capitalization consistent, but can remove emotional or semantic information.
  • Stemming reduces words to root-like forms and can produce truncated words.
  • Lemmatization converts words into valid dictionary forms called lemmas.
  • Stopwords are common words that may be filtered to improve efficiency.
  • Text vectorization converts text into numerical representations.
  • Bag of Words represents text using word frequencies.
  • TF-IDF measures the importance of terms within a document and across a corpus.
  • Tokenization divides text into smaller units called tokens.
  • NLTK provides functions such as word_tokenize() and sent_tokenize() for tokenization.
