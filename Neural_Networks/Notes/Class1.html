1. The Beginning of Machine Learning

Machine Learning (ML) allows computers to solve tasks by learning patterns and rules from data instead of having every rule explicitly programmed by a human.

In this course we will study applications such as:

  • Natural Language Processing (NLP)
  • Computer Vision
  • Deep Learning
  • Neural Networks

Why Machine Learning?

Some tasks are extremely simple for humans but difficult to describe using explicit rules for a computer.

Conversely, computers can perform some tasks that are difficult for humans, such as processing very large quantities of data or performing repetitive calculations.

Example: Chess

Chess is easy to understand at a conceptual level for humans, but describing every possible situation and strategy using manually programmed rules is extremely difficult.

Machine learning can instead learn useful patterns from historical experience.

2. What Is Machine Learning?

Machine learning algorithms use historical information and examples to learn a model capable of making predictions or decisions.

Training Data → Machine Learning Algorithm → Learned Model

The objective is to find a model that maps the input data to the corresponding output:

f(X) → Y
Core idea: Instead of explicitly programming every rule, we provide examples from which the algorithm learns the relationship between inputs and outputs.

3. Classification Problems

One important type of machine learning problem is classification.

In a classification problem, the model assigns an input to one of several predefined classes.

Multiclass Classification

A multiclass classification problem contains more than two possible classes.

For example, the Iris dataset contains three species of iris:

  • Iris setosa
  • Iris versicolor
  • Iris virginica

4. The Iris Dataset Problem

The Iris dataset traditionally contains measurements such as:

  • Sepal length
  • Sepal width
  • Petal length
  • Petal width

There are several limitations to consider.

Human Measurement Error

Measurements may contain errors because they were originally collected by humans.

Deployment Problem

After deploying a model, measuring the petal and sepal manually is not necessarily practical.

Using Images Instead

Instead of manually measuring the flower, we could take a photograph and use the image pixels as the input features.

The input representation changes from manually engineered measurements to raw image data.

5. Example: Recognizing a Vehicle

Suppose we want to formulate rules for recognizing whether an image contains a vehicle.

A traditional approach might require manually defining features such as:

  • Number of wheels
  • Shape of the body
  • Presence of windows
  • Presence of mirrors
  • Other visual characteristics

This creates a problem: defining reliable characteristics manually becomes increasingly difficult as the complexity of the task increases.

For example, vehicles can have very different shapes, sizes, viewpoints, lighting conditions, and mirror configurations.

6. End-to-End Learning

End-to-end learning is the approach followed in this Deep Learning course.

Traditional machine learning commonly contains a separate feature extraction stage:

Raw Data → Feature Extraction → ML Model → Prediction

In an end-to-end deep learning approach, the neural network can learn useful representations directly from the original data:

Raw Data → Neural Network → Prediction
The model learns both useful features and the mapping from those features to the final output.

7. Train/Test Split

A dataset is commonly divided into separate subsets for training and evaluation.

Dataset Purpose
Training set Used to learn the parameters of the model.
Test set Used to evaluate how well the trained model generalizes to unseen data.

Exploratory Data Analysis

Before training a model, we perform Exploratory Data Analysis (EDA) to understand the dataset, identify patterns, detect errors, and inspect the characteristics of the data.

8. Images and Neural Networks

Image Channels

When training a Convolutional Neural Network (CNN), the number of channels in the input image must be considered.

Image Type Number of Channels
Grayscale 1
RGB / Color 3

A grayscale image contains one intensity value per pixel. An RGB image contains three channels:

  • Red
  • Green
  • Blue

Image Size

Many machine learning models expect their input data to have a consistent dimensionality.

Therefore, if images have different sizes, they may need to be resized or otherwise transformed before being provided to the model.

9. Epochs

An epoch is one complete pass through the training dataset during the training process.

Epoch = how many times the model passes through the complete training dataset.

More epochs do not automatically mean a better model. Training for too many epochs can lead to overfitting.

10. Deep Learning and Dataset Size

The amount of available data affects which models are appropriate.

  • Traditional ML models and small neural networks can perform well with relatively small datasets.
  • With massive datasets, larger neural networks can often achieve better performance.
  • Larger models require more computational resources and generally take longer to train.
More data can make larger neural networks useful, but the computational cost also increases.

11. The First Artificial Neuron

McCulloch-Pitts Neuron

The first important mathematical model of an artificial neuron was proposed by Warren McCulloch and Walter Pitts in 1943.

Their model was inspired by biological neurons and attempted to represent how neurons could process information.

1943: McCulloch and Pitts propose a mathematical model of a neuron.
1960s: Interest in neural networks declined due to limitations in the available models and computational resources.
2012: Geoffrey Hinton and his collaborators achieved a major breakthrough in the ImageNet competition using deep convolutional neural networks.

12. Biological vs. Artificial Neurons

Biological neurons communicate using electrical and chemical signals, transmitting information through connections called synapses.

Artificial neural networks are inspired by this general idea, but they are mathematical models.

Artificial neural networks are inspired by biological neurons, but they should not be interpreted as exact simulations of how biological brains work.

Forward Propagation

The process of passing information from the input layer through the network toward the output is called forward propagation or forward pass.

Input → Hidden Layers → Output

13. McCulloch-Pitts Artificial Neuron

The original McCulloch-Pitts neuron receives binary inputs and produces a binary output.

The inputs can be interpreted as:

  • Excitatory inputs: contribute toward activating the neuron.
  • Inhibitory inputs: prevent or suppress activation.

Basic Components

An artificial neuron can be understood as having two fundamental operations:

  1. Aggregation of the inputs
  2. Activation based on the aggregated value

14. Aggregation Function

The aggregation function combines the input values.

In a simple neuron, this can be represented as a sum:

Σ xi

In modern neural networks, the inputs are normally multiplied by weights before being summed:

z = Σ wixi + b

where:

  • xi = input
  • wi = weight associated with the input
  • b = bias
  • z = aggregated value

15. Activation Function

The activation function determines the output of the neuron based on the aggregated input.

y = f(z)

In the original McCulloch-Pitts model, the output was binary. The neuron could therefore behave approximately as an on/off unit.

Modern neural networks use many different activation functions, such as:

  • Sigmoid
  • ReLU
  • Tanh
  • Softmax

16. Limitations of the McCulloch-Pitts Neuron

The original model had important limitations:

  • The inputs were binary.
  • The output was binary.
  • The model did not learn its parameters.
  • The inputs effectively had fixed importance rather than learnable weights.

These limitations motivated the development of more flexible artificial neurons.

The Perceptron

The perceptron introduced the idea of learnable weights, allowing the model to learn how important each input is.

z = w1x1 + w2x2 + ... + wnxn + b
McCulloch-Pitts neuron → fixed binary logic.
Perceptron → learnable weights.
